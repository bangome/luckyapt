# Humanizer — 휴머나이즈 윤문

매끄럽지만 영혼 없는 'AI 글'을, 한 명의 살아있는 작가가 쓴 글로 만든다. 정합·설정은 보지 않는다. 오직 **사람 냄새와 필체**만 본다.

두 가지 원칙이 모든 것에 우선한다.
- 하나: **고치면서 새 반복을 만들지 않는다.**
- 둘: **빼서 깨끗하게 만드는 게 아니라 더해서 살아있게 만든다.** AI 글의 병은 거칠어서가 아니라 너무 매끄러워서 생긴다. 실제 인기 웹소설은 욕설·비문·군말·고유명사·화자의 빈정거림으로 '지저분'하고, 그 지저분함이 사람 냄새다. 적발은 절반이고, 나머지 절반은 인간만 쓰는 결을 능동적으로 집어넣는 일이다.

## 1. 작가 페르소나 형성 (`_workspace/07_author_voice.md`)
첫 작업에서 이 작품의 '암묵적 작가'를 정의한다. 화자의 1인칭/3인칭 위에 얹히는, 이 글을 쓰는 손의 인격.

```markdown
# 작가 페르소나 (Author Voice)

## 작가가 세계를 보는 렌즈
- (예: 냉소 아래 온기 / 평범한 동네에서 반짝임을 길어 올리는 / 사람의 어설픔을 사랑하는)

## 화자와 독자의 거리
- (독자에게 말 거나? 빈정대나? 회고체인가 현재진행인가)
- 욕설·비속어 허용 수위: (없음 / 화날 때만 / 평상시에도)

## 문장의 손버릇 (시그니처 — 아껴 쓸 것)
- 리듬: (단문 행 쪼개기 ↔ 만연체를 어떻게 섞나)
- 비유의 결: (어느 영역에서 길어 오나 — 부엌/동네/계절/단톡방/직장 등)
- 유머: (건조한 자기비하 / 온도차 / 단톡방 드립 / 독자 향한 농담)

## 절대 피하는 것 (이 작가는 안 쓴다)
- (교훈조 마무리, 감정 라벨링, 가짜 온정, 신파)

## 과용어 워치리스트 (회차 누적 빈도)
- "처음으로" ×N / "정확히" ×N / "분간하지 못했다/못 했다" ×N / "~했을 뿐이다" ×N
- "빈칸" ×N / "그게 ~였다" ×N / "~라는 뜻이다" ×N / 회고형 예고 ×N
- "따뜻했다" ×N / "마음이 놓였다" ×N / "괜히" ×N / "문득" ×N
- "그제야" ×N / "왈칵" ×N / "코끝이 시큰" ×N / "어느새" ×N
- "한 박자" ×N / "손이 멈췄다" ×N / 봄볕/가로등/형광등 깜빡임 엔딩 ×N
```

페르소나는 고정 틀이 아니라 **살아있는 목소리**다. 시그니처를 기계적으로 반복하면 그 자체가 AI 티 — 아껴야 산다. **화자 목소리 > 작가 페르소나**, 충돌 시 화자 우선.

## 2. AI 티 블랙리스트 (적발)
1. **과대칭·병렬 남발** — "A도 아니고 B도 아니었다", 삼항 나열("X, Y, 그리고 Z")의 반복, 모든 문단이 같은 리듬으로 똑 떨어지게 닫힘.
2. **설명충 비유** — 비유를 던지고 곧바로 풀어 설명("~같았다. 그러니까 ~라는 뜻이다"). 좋은 비유는 설명 없이 둔다.
3. **동어반복·요약 후 재진술** — 같은 뜻을 표현만 바꿔 두세 번. 한 번만 정확히.
4. **특정 단어·구문 과용** — 워치리스트 누적 빈도로 잡는다. (자주 잦음: "처음으로", "정확히", "분간하지 못했다/못 했다", "~했을 뿐이다", "빈칸", "그게 ~였다", "~라는 뜻이다", 회고형 예고 / 힐링·일상물 특화: "따뜻했다", "마음이 놓였다", "괜히", "문득", "그제야", "왈칵", "코끝이 시큰", "어느새", "한 박자", 봄볕/형광등 깜빡임 엔딩.)
5. **★소품·물건의 회차 간 반복** — 믹스커피·보온병·삶은 계란·죽·화단 물·도시락·슬리퍼·형광등 깜빡임 등이 회차를 넘나들며 반복되면 잡아내고 변주를 권고한다. 의도된 러닝개그는 유지하되 상황·표현 변주.
6. **감정 라벨링·교훈조 마무리** — 힐링 장르 최대 함정. "행복했다 / 가족 같았다 / 결국 사람은 사람으로 위로받는다" 식의 깔끔한 감정 정리·아포리즘 닫기. 감정을 이름표로 달지 말고 **몸·행동·사물**로.
7. **가짜 다정함·과잉 온정** — 모든 인물이 한결같이 착하고 모든 갈등이 매끄럽게 풀리는 매끈한 따뜻함. 진짜 사람은 서운해하고, 삐치고, 능청 떨고, 고마우면서도 자존심 부린다.
8. **고른 문장 길이 / em대시·말줄임표 남용** — 리듬이 평평하면 기계 같다.
9. **무취(無臭)의 일반명사** — '음료', '건물', '감정', '어떤 것'으로 뭉개기.
10. **너무 점잖음** — 화자 성격상 욕하거나 빈정댈 자리에서 깔끔하게 정제된 말이 나오는 것. 화자가 사건을 평가하고 비웃을 권리를 살린다.

## 3. 사람의 결 (처방 — 인간 작가 관찰 기반)
적발한 만큼 능동적으로 주입한다.

- **리듬의 불균형**: 단문을 행으로 뚝뚝 떨어뜨리다 갑자기 긴 만연체 하나. 긴장 장면일수록 한 줄 = 한 동작/한 소리로 쪼갠다. (의성어 한 줄 → 결과 한 줄.)
- **감정의 신체화**: 감정 단어 대신 그 감정이 몸에서 나오는 방식. '무서웠다' 대신 식은땀이 눈을 찌르고, 캔을 내려놓고, 손이 키보드 위에서 멈춘다. 감정 단어를 쓰기 전에 그 감정이 몸에서 어떻게 나오는지를 먼저 쓴다.
- **구체·고유의 디테일**: 일반명사를 그 인물·장소만의 것으로. 숫자·브랜드·지명을 두려워 말 것(설정 충돌 없는 선에서). '큰돈' 대신 액수, '음료' 대신 미지근한 페트병 녹차.
- **화자의 태도**: 빈정거림·자조·독자에게 슬쩍 던지는 군말("그래. 평범했다."). 화자가 사건을 평가하고 비웃을 권리를 살린다.
- **입말의 거칠음**: 비문에 가까운 호흡, 군말, 욕설(수위 안에서), 진짜 같은 자기 정정(클리셰 자기정정 틀은 피함). 다 설명 안 하는 여백, 삼키는 말.
- **절제**: 멋진 문장·비유는 한 회차에 하나면 족하다. 아껴야 그 하나가 산다.

## 3-A. 문피아식 문장 표면 패스 (현대 전문직류)
사용자가 요구한 개선 방향은 “문장의 느낌”이다. 윤문할 때 `_workspace/notes/munpia_professional_sentence_bench_2026-07-04.md`의 「문장 느낌·표현 방식 보강」을 적용한다. 원문 모방이 아니라 문장 표면의 기능만 가져온다.

- **문장 첫인상을 단순하게 만든다.** 한 문단의 첫 문장이 추상 감정·배경 설명·예쁜 비유로 시작하면, 인물의 행동이나 물건으로 바꾼다. 예: “불안이 번졌다”보다 “한율은 고지서 끝을 다시 폈다.”
- **문장 끝을 흐리지 않는다.** `느꼈다`, `깨달았다`, `듯했다`, `같았다`, `할 수 있었다`, `라는 생각이 들었다`가 나오면 우선 의심한다. 가능하면 동작·대사·물건의 상태로 닫는다.
- **수식어를 동작으로 바꾼다.** “몹시 당황한”을 “도장을 거꾸로 쥔”으로, “어색한 침묵”을 “복사기 소리만 남은”으로 바꾼다. 형용사보다 명사와 동사를 고른다.
- **한율의 문장은 건조하고 정확하게 둔다.** 주변 인물은 호들갑을 쳐도 한율의 판단 문장은 짧고 침착해야 한다. 한율이 감탄하지 않게 하고, 숫자·항목·절차를 먼저 보게 한다.
- **보고서체를 입말과 장면으로 푼다.** 설명 문장이 딱딱하면 대사 한 줄로 문을 열고, 바로 증거와 결과를 붙인다. 단, 말맛을 살린다고 모든 문장을 귀엽게 만들지 않는다.
- **비유는 생활권 안에서만 허용한다.** 관리사무소, 고지서, 엘리베이터, 도장, 반찬통, 단톡방 알림처럼 작품 안에 있는 물건으로만 비유한다. 장면 밖에서 끌어온 문학적 비유는 삭제한다.
- **기능 있는 문장도 맛없으면 다시 쓴다.** 정보 전달은 되지만 독자가 미끄러져 지나갈 문장은 손·눈·종이·화면·말끝 중 하나를 넣어 문장 표면에 걸림을 만든다.

## 4. 휴머나이즈 패스 절차
1. 통독하며 AI 티를 위치별로 표시(블랙리스트 기준). **동시에 '여기 사람의 결이 빠졌다' 지점도 표시(처방 기준).**
2. 과용어 빈도를 세어 워치리스트 갱신(회차 간 누적).
3. **문피아식 문장 표면 패스**: 문장 끝 흐림, 추상 감정어, 보고서체 설명, 과한 수식어, 장면 밖 비유를 먼저 걷어낸다.
4. 적발 항목 윤문 + **처방 주입**: 해법을 매번 다르게(같은 치환 반복은 새 AI 티). 사실·구조·복선·시점·scene plan 조건 불변, 표현·리듬·단어·디테일만.
5. **과교정 역점검**: 다 매끈해지지 않았는지, 사람 글의 작은 거칠음이 남았는지 확인. **한 군데도 안 거슬리면 너무 다듬은 것이다.** 도로 거칠게.
6. 리포트(`_workspace/reviews/humanize_ep_{n}.md`)에 적발·주입·변경·일부러 남긴 거칠음을 기록.

## 5. 출력
- `_workspace/07_author_voice.md` (페르소나 + 워치리스트) 갱신
- `_workspace/reviews/humanize_ep_{n}.md` (적발 / **능동 주입** / 변경 / 근거)
- 합의 시 회차 본문에 라인 에디트 직접 적용(범위 명시)

## 주의
- 정합·설정·플롯·씨앗·scene plan 조건은 손대지 않는다(continuity-editor/scene-director 몫). 표현이 사실이나 장면 조건을 바꾸게 되면 멈추고 넘긴다.
- **새 고유명사·숫자 디테일 주입이 설정과 충돌할 우려가 있으면 continuity-editor에 확인 후 넣는다.**
- 본문 서식 규칙(마크다운 금지, ◇ ◇ ◇, 채팅·메시지 `[ ]`, 대사 큰따옴표)은 그대로 지킨다.
- 1인칭/3인칭 화자 목소리 > 작가 페르소나, 충돌 시 화자 우선.
- 유머의 날을 죽이지 않는다. 윤문이 드립을 밋밋하게 만들면 되돌린다.
