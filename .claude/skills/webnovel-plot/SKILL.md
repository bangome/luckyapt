# Webnovel Plot — 힐링 웹소설 플롯·구성

세계관과 군상 인물을 연재 가능한 따뜻한 이야기로 조립한다. 핵심은 **매 회차 다음을 누르게 만드는 구조**와 **잔잔한 흐름의 응집력**을 동시에 잡는 것. 단, 긴장과 공포가 아니라 궁금증·여운·웃음으로 끌어간다.

## 작성 원칙
- **거시 → 미시.** 전체 흐름 → 국면(시즌/계절) → 에피소드 → 회차(편) 순으로 분해한다.
- **힐링 웹소설 문법.** 1화는 따뜻하게 끌어들임(평범한 일상에 드는 작은 빛). 매 회차는 도입 훅(소소한 궁금증·웃음) + 잔잔한 전개 + 따뜻한 절단. 위로와 웃음을 교차 배치.
- **따뜻한 절단.** 다음 화를 누르게 하되 '궁금증·따뜻한 여운·웃음' 유발형으로. 서늘한 절단(공포·위협)은 쓰지 않는다. 회차는 *사건이 끝나는 곳*이 아니라 독자가 "어? 잠깐만" 하는 지점에서 닫고, 끝에 질문 최소 1개(왜/누구/어떻게/그래서/이제 어떻게)를 남긴다. 절단 메커니즘 6유형과 3대 금지(사건 완전 해결·일상 마무리·억지 반전)는 `06_engagement_brief.md` §6 정본.
- **갈등을 따뜻한 사건으로.** 주제를 추상으로 두지 말고 독자가 함께 웃고 뭉클해하는 에피소드(오해와 화해, 곁을 지키기)로 번역한다. 누구도 파괴되지 않는다.
- **관계 떡밥으로 호기심을 깐다.** 관계의 궁금증(멤버의 사연, 티격태격하던 둘의 화해)을 사전 회차에 심고, 갑작스럽지 않게 따뜻하게 풀어 복선·회수 목록으로 관리한다.

## 큰 흐름 (느슨한 골격)
인물들이 처음 모임 → 서로 가까워짐 → 작은 위기와 오해 → 곁을 지키며 화해 → 함께 조금씩 자람. (못 박는 전환점이 아니라 계절처럼 흐르는 국면)

## 출력 구조 (`_workspace/03_plot_structure.md`)
```markdown
# 럭키아파트 — 플롯·구성

## 1. 로그라인 & 전체 흐름
- 한 문장 로그라인 / 큰 흐름의 국면별 요약

## 2. 국면(시즌/계절) 분해
- 국면별: 제목 / 시기(계절·이벤트) / 핵심 정서 / 중심 인물 / 무대 공간

## 3. 에피소드 분해
- 각 국면 안의 에피소드: 작은 목표·갈등(오해·서운함)·따뜻한 해소

## 4. 회차별 시놉시스 (최소 1국면은 회차 단위까지)
- [n화] 제목
- 도입 훅(소소한 궁금증·웃음)
- 핵심 사건(잔잔한/뭉클한/웃긴)
- 등장 인물
- 인물/주제 기능(어떤 위로·웃음·성장)
- 관계 떡밥 심기/회수
- 따뜻한 절단: 정서타입(사이다/코미디/서스펜스/감동/반전) × 메커니즘(인물/선택/관계/호출/발견/의심) + **남길 질문 1개**(왜/누구/어떻게/그래서/이제 어떻게). 단 이 화의 민원·관계·감정 하나는 해결. (`06_engagement_brief.md` §6 정본)
- prose-writer 인계 메모: 살릴 정서·웃음 포인트·대사 톤

## 5. 국면 흐름 지도
- 처음 모임 / 가까워짐 / 작은 위기 / 화해 / 함께 자람 — 각 회차 위치

## 6. 관계 떡밥·회수 목록
- [떡밥 ID] 심는 회차 → 회수 회차 / 내용(관계의 궁금증, 따뜻한 회수 방식)
```

## Prose Writer 인계 메모 작성 규칙
회차가 뭉클한 순간·웃긴 해프닝·화해 장면을 포함하면, 회차 시놉시스 끝에 다음을 간단히 남긴다.
- 살릴 정서: 예) 새벽 단톡방의 적막한 위로, 오랜만의 재회의 머쓱함
- 웃음 포인트: 예) 오타로 번진 단톡방 폭소, 노안 때문에 벌어진 오해
- 대사 톤: 예) 맏언니의 무심한 듯 다정한 핀잔, 막내의 엉뚱한 솔직함
- 따뜻한 여운: 예) 답장 없이 남긴 이모티콘 하나의 의미

## 주의
- 인물 동기로 사건이 성립 안 되면 character-designer에 조정 요청.
- 갈등은 누군가를 파괴하지 않는다. 모든 마찰에 따뜻한 출구를 둔다.
- 실화 기반이므로 실제 인물의 사생활·명예를 해치지 않도록 픽션으로 충분히 승화한다.
- 본문(소설 문장)은 쓰지 않는다. 시놉시스까지만.
