# Humor Design — 유머·드립·명대사 설계

럭키아파트의 '재미' 절반을 책임진다. 웃음을 우연이 아니라 **설계**로 만든다. 작품 전체에 깔리는 코미디 구조(러닝 개그·펀치라인·인물별 웃음 문법·콜백)와, 웃음 너머 곱씹는 따뜻한 명대사를 함께 관리한다.

## 세 종류
| 구분 | 러닝 개그/밈 | 펀치라인/장면 웃음 | 따뜻한 명대사 |
|------|------------|-------------------|--------------|
| 목적 | 반복될수록 정듦, 회차마다 변주 | 특정 장면 빵 터뜨림 | 곱씹게 함, 힐링의 못 |
| 조건 | 따라 하기 쉽고 변주 가능 | 타이밍·낙차·받아치기 | 짧고 리듬 있고 진심의 울림 |
| 배치 | 작품 전반(러닝) | 회차 내 결정적 한 컷 | 희소하게, 결정적 순간 |

## 작성 원칙
- **인물에서 나온다.** `character-design` 목소리 가이드를 응축한다. 웃기지만 그 인물이 할 말이 아니면 버린다. 멤버마다 '웃음 담당 포지션'을 분산한다.
  - 웃음 문법 예시 포지션: 자학개그형 / 팩폭·돌직구형 / 허당·천연형 / 과장 리액션형 / 건조한 한 줄형(드라이) / 맞장구 폭주형 / 진지하게 엉뚱한형
  - 한 단톡방에 같은 포지션이 둘 이상이면 톤을 갈라 차별화한다.
- **단톡방 드립을 자산화한다.** `00_sources_master.md` §원본 `00_source_voice_patterns.md`의 날것 말맛을 본문용으로 정제한다 — 자모반복(ㅋㅋ/ㅠㅠ)·맞춤법 파괴·과장 리액션·갑분싸·드립 받아치기·한 사람 연속 폭격. 카톡 화면 인용 웃음과 내레이션 웃음을 구분해 둔다.
- **러닝 개그는 변주로 산다.** 같은 라인·상황이 회차가 바뀌며 다른 의미로 터지게(웃김 → 더 웃김 → 뭉클함). 심는 회차와 변주·페이오프 회차를 짝짓는다.
- **웃음과 따뜻함을 엮는다.** 긴장·서운함 직후의 웃음(숨통), 웃다가 찡해지는 낙차. 슬픈 회차 직전에 쌓은 웃긴 라인이 나중에 뭉클하게 메아리치게 콜백을 건다.
- **남발 금지.** 모든 줄에서 웃기려 하면 다 안 웃긴다. 명대사가 흔하면 무게가 죽는다. 회차별 웃음 밀도를 plot에 맞춰 조절한다.
- **공격적 웃음 금지.** 약자·외모·처지 조롱, 특정 인물 깎아내리기 금지. 함께 웃는 웃음, 애정의 결 안의 놀림.
- **자연스러운 한국어 입말.** 번역체·작위적 신조어 남발 금지. 실제로 입에 붙는 라인.

## 출력 구조 (`_workspace/05_humor_lines.md`)
```markdown
# 럭키아파트 — 유머·드립·명대사 집

## 1. 인물별 웃음 문법
### {인물}
- 웃음 포지션 / 말버릇·드립 패턴 / 대표 라인 예시

## 2. 러닝 개그·밈
- [개그 ID] 최초 등장 상황 / 변주 방식 / 반복 포인트 / 정드는 메커니즘

## 3. 펀치라인·티키타카
- [라인 ID] "대사/주고받기" — 어느 장면, 무엇으로 터지나(타이밍·낙차·받아치기)

## 4. 따뜻한 명대사
- [라인 ID] "대사" — 어느 순간에, 무엇을 곱씹게 하나

## 5. 콜백 매핑
- [ID] 심는 회차 → 되돌아오는 회차 / 효과(웃음/뭉클함/반전)
```

## 주의
- 본문(소설 문장 전체)을 쓰지 않는다. 웃음·드립·라인과 그 운용만. prose-writer가 회차에 심고, continuity-editor가 일관 사용을 검수하며, critic이 재미를 평가한다.
- 확정·회자된 라인·러닝 개그는 함부로 바꾸지 않는다(일관성). 신규 회차 라인은 추가한다.
- 실명·식별정보가 묻은 원료는 가명화·각색 후 자산화한다.
