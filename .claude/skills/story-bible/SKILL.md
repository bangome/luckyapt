# Story Bible — 작품 바이블 작성

세계관은 인물과 플롯이 딛고 설 토대다. 한 번에 모든 걸 설명하는 백과사전이 아니라, **이야기를 떠받치고 따뜻한 떡밥을 품은** 살아있는 설정집을 만든다. 럭키아파트는 거창한 사건이 아니라 일상의 반짝임으로 읽는 이의 마음을 데우는 힐링 웹소설이다.

## 작성 원칙
- **따뜻함을 규칙으로 박는다.** 모든 갈등에 화해·이해·작은 성장의 출구를 함께 설계한다. 독자가 "읽고 나니 마음이 데워졌다"고 느끼게 하는 것이 이 작품의 정체성이다. 서늘함·악의·범죄는 없다.
- **일상 무대는 '왜 거기서 마음이 움직이나'로.** 단톡방·동네/아파트·직장·가정 각 공간에 고유한 정서·관계의 질감·등장 이유를 부여한다.
- **따뜻한 떡밥을 심는다.** 추리용 미스터리가 아니라 관계의 궁금증(저 멤버는 왜 새벽에만 깰까, 늘 핀잔 주는 그 언니의 사연은)을 회차마다 풀어갈 목록으로 미리 정리한다.
- 소재(실화) 질감이 필요하면 직접 지어내지 말고 source-miner 산출물(`_workspace/00_source_*.md`)을 참조한다.

## 시점·형식 결정 가이드 (중요)
시점/형식은 임의로 확정하지 않는다. 아래 옵션을 장단과 함께 제시하고 결정을 받는다.
- **1인칭 단일주인공:** 몰입·정서 직설에 강함 / 단톡방 다성성은 약함.
- **단톡방 군상극(다수 화자/시점 순환):** 여러 인물의 일상이 교차하는 따뜻함 / 몰입 분산 위험.
- **3인칭 관찰자(따뜻한 내레이터):** 군상과 거리감의 균형 / 정서 직설은 절제됨.
결정 전까지는 바이블에 '시점 미정 — 옵션 A/B/C'로 명기하고 후속 작업이 막히지 않게 한다.

## 출력 구조 (`_workspace/01_worldbible_setting.md`)
```markdown
# 럭키아파트 — 작품 바이블

## 1. 작품 정체성
- 로그라인 / 톤·분위기(따뜻함·위로·유머·일상의 반짝임) / 장르 좌표 / 핵심 주제(소소한 성장과 연결)

## 2. 무대·공간
- 단톡방 커뮤니티('경리들모임' 원형): 정서, 말 텀, 모임의 규칙
- 동네/아파트: 단지의 소문과 정, 공간의 질감
- 직장 / 가정: 피로와 동료애, 일상의 안식처
- 공간별: 질감 / 이곳에서 마음이 움직이는 이유 / 등장 이유

## 3. 등장 커뮤니티·관계망
- 모임의 구성과 결(나이대·역할·암묵적 위계 아닌 정서적 거리)
- 관계망 한눈 지도(누가 누구와 가깝고 누가 늘 티격태격하나)

## 4. 일상 속 갈등·치유의 규칙
- 이 세계에서 갈등은 어떻게 생기고 어떻게 풀리는가(오해→이해, 서운함→화해)
- '상처를 주는' 사건은 없다. '서로를 알아가는' 사건만 있다.

## 5. 소소한 미스터리·관계 떡밥 목록
- [떡밥 ID] 내용(관계의 궁금증) / 언제쯤 풀림 / 따뜻한 회수 방식

## 6. 시점·형식 결정 가이드
- 옵션 A/B/C 장단 정리 / 현재 결정 상태(미정/확정 + 근거)

## 7. 추후 보완 / 소재 확인 요청 항목
```

## 주의
- 본문(소설 문장)을 쓰지 않는다. 설정만.
- 실화 기반이므로 실제 인물의 사생활·명예를 해치지 않도록 픽션으로 충분히 승화한다. 실명·식별 가능한 디테일은 변형한다.
- 시점/형식을 임의 확정하지 않는다.
