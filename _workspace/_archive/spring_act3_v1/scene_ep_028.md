## 1. 회차 목적

- **독자에게 줄 것:** 채연주의 "덕분에 불안증이 가셨어요"(채연주 아크 1차 완결 + 가장 뭉클한 대사) + 단톡방 '이방 한정 아이돌' 추대로 웃음으로 닫히는 3막 — **뭉클함과 웃음이 같은 회차에 공존하는 힐링 정점**.
- **기능(3막 10화차 = ★막 닫기):**
  1. **채연주 "덕분에 불안증이 가셨어요"(씨앗3 최종 발화):** 채연주 아크의 감동 정점. 자책형 캐릭터가 처음으로 '그건 내 잘못이 아니었다'에 가까워지는 순간. ★신파 0 — 채연주가 감사함을 직접 표현하는 간결한 한 줄.
  2. **단톡방 '이방 한정 아이돌' 추대(RG-5 첫 발화):** 나은서가 먼저 "이방 한정 아이돌 등극이시오이다!" → 채연주 동조 → 무물(무엇이든 물어봐) 공세 → 한율 당황. 정체 들킬 뻔 코미디(RG-5 씨앗). 이방 한정 아이돌이 단지 단톡방이 아닌 '경리들모임' 단톡방에서 먼저 추대됨(설계 주의).
  3. **행운아파트 사무소 편입 비트:** 3막 닫기에서 한율이 단지 식구들에게 한 칸 더 스며드는 것을 보여주는 짧은 비트.
  4. **4막 브릿지(씨앗 1컷):** 29화(백영자 44건 첫 실패) 진입을 위한 도화선 — 44건 민원인의 첫 등장 또는 예고 한 컷.

  - 건너뛴 폭: 하룻밤.
  - 이동 동기: "내일 한율은 채연주씨에게 한 가지를 더 보내려고 했다"는 절단의 이행.

- **감정 비트 흐름:** 상경 퇴근(코미디 완충) → 4막 씨앗 전화(잔가시) → 한율 3막 닫기 속말(따뜻하게·가볍게) → 봄 저녁 이미지.
