## 0. 에피소드 대전제 (왜 이 3화인가)

- **목적 = ① 한율의 능력을 보여주는 것 + ② 채연주 호감도 상승.** ★채연주 '구제'가 목적이 아니다.
- **분량 = 딱 3화.** 타 단지(채연주 830세대) 이야기를 3화 넘게 끌면 문피아 독자가 "행운아파트 이야기는 언제?" 이탈 → 21화 승인제 결말로 닫고 22~28은 단지 일상 복귀.
- **폐기된 구 설계:** 봄 3막 19~28 통째 throughline / 취업규칙 산정기준 개정 대장정 / 노동청→위탁사→노무사→소송 / 처우 완전정상화 5부 이월(다시봄-B2 SP-채연주2). → 전부 폐기.
- **정합 토대:** 8~12화에서 채연주는 이미 (취업규칙) 조항 찾고, 명세서 모으고, 청구 시도까지 한 상태. 20화의 한율 조언은 '처음부터 다 떠먹이기'가 아니라 그 위에서 **'현실적으로 어디까지 가능한지'를 정리해 주는 단계.**
- **무대:** 채연주는 차도관리 산하 **타 단지 경리**(단톡방 '경리들모임' 동료). **대면 0 — 모든 교류는 단톡방으로만.** 한율의 도움이 자기 사무소 담장 밖으로 처음 뻗는 확장 비트(세계가 잠깐 830세대로 넓어졌다 다시 단지로 복귀).

## 1. 19화 — 하소연 (도입 훅)

- **회차 목적:** 사건 점화. 채연주의 처지("야근했는데 돈 못 받는다")를 독자에게 각인하고, 한율의 '손이 멈추는' 능동 진입을 건다. 동료애·짠함 적립.
- **5박자 요지:**
  1. 오늘의 현장 소동 = 단톡방에 채연주가 하소연을 쏟는다(830세대 혼자 떠안는 처지·말일 부과 마감 야근 지옥). 단톡방 동료들 위로 릴레이.
  2. 한율의 오판/문화충격 = 한율이 곧장 '계산상 청구 가능액'부터 들이밀려다, 채연주가 원하는 건 숫자가 아니라 '들어주는 것'임을 한 박자 늦게 감지(능력↔사람결 갭).
  3. 숫자의 이상 징후 = 채연주가 흘린 명세서·근무기록의 결이 어긋남을 한율이 본다(손이 멈춤). 단, 여기선 '풀이' 시작 안 함 — 다음 화로 넘김.
  4. 작은 보상 = 관계 보상(한율이 "일단 가진 기록 다 모아 보세요" 한마디로 채연주가 처음 숨을 고름) + 정봉구 보온병/삶은 계란 결의 온기 한 컷(단지 동료 정).
  5. 다음 화 잔가시 = "그래서… 받을 수는 있어요?" 채연주의 물음 → 한율이 "어디까지 가능한지 정리해 볼게요" (따뜻한 절단·궁금증).
- **엔딩타입:** 감동(짠함·동료 온기) 또는 사이다 예고. ★18화 사이다와 인접 반복 피하려면 **감동** 권장.
- **위장 cadence(가볍게 한 톨):** 환대·동료애가 따뜻할수록 '정 주는 데 서툰 내가 왜 이렇게까지 / 나는 곧 떠날 사람인데' 죄책감 1줄(§3-B(1)). ★식은땀·서늘 신체화 0 — 자조·여운으로.
- **윤솔 제동 1컷:** "그게 우리 일 맞아요? / 타 단지 일까지 왜 나서요" 한 컷(미움 아님·실리적 우려). 한율 능동↔윤솔 거리감 충돌.

## 2. 20화 — 한율의 현실적 조언·정리 (능력 부각 본편)

- **회차 목적:** ★한율의 능력을 보여주는 핵심 화. 베테랑 경리의 현실 감각으로 '감정 싸움'을 '기록 싸움'으로 번역.
- **5박자 요지:**
  1. 오늘의 현장 소동 = 채연주가 모은 기록(명세서·근무기록·취업규칙 조항)을 단톡방으로 올린다. 동료들 갑론을박(다 받아내라 vs 괜히 찍힌다).
  2. 한율의 오판/문화충격 = 한율이 '법적으로 완벽한 청구'를 먼저 말했다가, 그게 채연주 입장에선 '회사와 전면전'이라 현실에서 안 먹힐 수 있음을 자각(맞는 답≠먹히는 답·백영자 학습의 결).
  3. 숫자의 이상 징후 = 한율이 기록을 분해 — 어디까지가 '입증되는 야근'이고 어디부터가 '증거 없는 주장'인지 선을 긋는다(소급 청구 현실 한계). 손이 멈추는 회계 장면.
  4. 작은 보상 = 추리/사이다 보상. 한율의 **현실적 조언 3원칙**:
     - **증거를 남겨라** (출퇴근·업무 로그·승인 흔적을 그날그날 기록).
     - **기록을 모아라** (이미 지난 야근은 입증되는 분만, 감정 아닌 자료로).
     - **감정적으로 싸우지 마라** (전면전 대신 '앞으로의 구조'를 바꾸는 쪽으로).
     → 채연주가 "이렇게 정리해 주는 사람은 처음"이라며 안도(호감도 상승).
  5. 다음 화 잔가시 = 한율이 "전액 소급은 어렵겠지만, 앞으로는 손해 안 보게 만들 방법이 있어요" → 21화 승인제 예고(궁금증).
- **엔딩타입:** 반전 또는 사이다(현실의 선을 긋는 통쾌함). ★19 감동과 인접 반복 피하려 **반전**('다 받아내기'가 아니라 '구조를 바꾸기'로 방향 비틂) 권장.
- **위장 cadence:** §3-B(1) 20~21 부근 죄책감 1줄(능동 사이다에 위장 그림자 한 톨).

## 3. 21화 — 결과 통보 = 야근 사전 승인제 도입 (결말·사이다)

- **회차 목적:** 에피소드 완결. 한율이 현실의 선을 그어주는 사이다 + ★정체 환기 비트.
- **★승인제 결말 메커니즘(구체):**
  - **소급:** 전액 소급은 못 받는다 — 입증되는 분만 일부 정리(현실 결말·과장 사이다 금지).
  - **앞으로:** **야근 사전 승인제** 도입 — 야근은 사전에 승인·기록되고, 기록된 야근은 보상된다. "다음부터는 일한 만큼 남는다."
  - **범위:** 취업규칙 산정기준 '개정 대장정'은 폐기. 한율은 **'승인제 + 간단한 기준 정비'를 정리해 채연주(혹은 그쪽 담당)에게 넘기는 선까지**만 — 별도 회차로 끌지 않는다.
  - **메시지:** "지나간 건 다 못 받아요. 그런데 앞으로 야근하는 만큼은, 이제 사라지지 않아요." (현실의 선=사이다).
- **5박자 요지:**
  1. 오늘의 현장 소동 = 채연주가 결과를 단톡방에 보고(긴장).
  2. 한율의 오판/문화충격 = 채연주가 '전액 못 받음'에 잠깐 실망 → 한율이 '구조가 바뀐 게 더 큰 승리'임을 짚어줌.
  3. 숫자의 이상 징후/정리 = 승인제 도입 전후 비교(앞으로 한 달이면 얼마가 남는지) 한 컷.
  4. 작은 보상 = 사이다 보상(현실의 선) + 관계 보상(미화/경비 커피 박스 합법 예산 처리·단톡방 '이 방 한정 아이돌' 결). 채연주 "덕분에 불안증이 가셨어요" 결.
  5. ★다음 화 잔가시 = **정체 환기 비트**(아래).
- **엔딩타입:** 사이다. ★20과 결이 다르도록(20=반전 권장 → 21=사이다).

### ★21화 말미 — 정체 환기 비트 (필수)

- **무엇:** 사건 종료 후 채연주(또는 단톡방 다른 동료)가 **"한율님은 왜 관리소 일을 그렇게 잘 알아요?"** 류로 묻는다.
- **목적:** ★정체 노출이 아니라 **'한율이 평범한 신입이 아니다'를 독자에게 다시 환기.** 독자만 안다(밀착 3인칭 한율 시점이라 한율의 속내 1줄로 처리).
- **한율의 처리:** 늘 하던 변명으로 가볍게 덮는다 — **"책을 좀 봤습니다" 류**(실없이·웃으며). 채연주는 "역시 책벌레" 정도로 넘어감.
- **독자 보상:** 한율의 속말 1줄(예: "책으로 배운 게 아니라는 걸, 이 방 사람들은 모른다") — 독자만 아는 윙크.
- **★누설 가드(불변):**
  - 단톡방으로만(채연주 대면 0).
  - 본명 **박한결 노출 0**.
  - 둘째 차윤수 밀명·차도그룹 본사 출신·위장 목적 누설 0.
  - 야근수당은 **채연주 단지 운영구조/처우 문제로 좁게** — 둘째(차도관리/위탁사) 비리와 직접 연결 0.
  - '들킬 뻔' 긴장으로 키우지 않는다(C형 본격 위장 위기는 9~12에서 이미 터뜨림·다음 봉우리는 6~7막). 여기선 **여운·자조 수준의 환기 1톨.**

## 4. 22~28화 복귀 방향 (7화, 채연주 throughline 종료)

- **방향:** 채연주 라인 완전 종료 → **행운아파트 단지 안 일상·공동체 에피소드(B/D형)로 복귀.** 메인 큰 비리/돈냄새는 예정대로 6~7막(53~72) — **22로 당겨오지 않는다.**
- **활용 자산(새 사건 대거 신설 아님·기존 일상 자산 재배치):**
  - 고만옥 온기(옥수수·믹스커피 먹이는 정)
  - 박만수 작황·새벽 화단/상추
  - 이봉식 정보망(차량 동선·현장 정보)
  - 정봉구 온기(밥상·보온병)
  - 입주민 앙상블(13~18 소개된 한재민·장태호·최미라·존 홍·강수진/박형철 부부 재등장 가능)
- **결·엔딩:** B형(일상 코미디) 주력 + D형(사연·연대) 1회. 엔딩 5타입 순환·인접 반복 금지(§1-C(3)). 19~21 능력 사이다(A형) 직후이므로 톤을 일상·온기로 환기.
- **위장 cadence:** 매 3~4화 가볍게 한 톨(들킬 뻔 긴장 아님·일상 이중성/죄책감 1줄). C형 본격 위협은 6~7막까지 아낌.
- **소재 중복 가드(5막 39~52와 분리):** 봄맞이 대청소·화단 분양제·재활용장 전쟁·길고양이 새끼 구조는 **5막 소관** — 22~28은 그와 겹치지 않는 단지 일상(일상 민원·동료·입주민 정 비트). ★22~28 각 화 시놉시스 세분은 추후 scene-director/prose 단계.
