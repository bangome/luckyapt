## 1. 회차 목적

- **독자에게 줄 것:** 한율이 처음으로 '자료 없이' 행동하는 장면 — 베테랑 경리가 숫자·분류표 없이 엘리베이터를 타고 702호 앞에 서는 것의 낯섦과 어색함. 문도 못 두드리고 돌아오는 코미디 + 그 과정에서 한율이 처음으로 '들으러 가는 것이 중요하다'를 몸으로 배우기 시작하는 전환.
- **기능(4막 4화차 — 집 방문 시도·서미정 거울 완성):**
  1. **자료 없이 엘리베이터:** 한율이 퇴근 전 충동적으로 704동(←304동) 엘리베이터에 타는 것 — 7층 버튼을 누르고 올라가는 동안의 속말. 서미정 거울 정서 완성.
  2. **문 앞에서 멈춤·코미디:** 702호 문 앞에 서서 벨을 누르지 못하는 것 — 이유를 모른 채. 그 자리에서 돌아서는 것.
  3. **엘리베이터 내려오는 길·고만옥:** 고만옥이 같은 엘리베이터에서 내려오며 "어디 갔다 와요?" 하는 것 — 한율이 "702호 갔다 왔어요"라고 했다가 '아뇨, 그냥 지나쳤어요'로 정정하는 낙차.
  4. **처음의 전환:** 집에 돌아와서 한율이 '들으러 가지 못했다'는 것을 아는 것 — 다음에는 들을 준비를 하고 가야 한다.

## 2. 장면 목록

### 〔씬 1〕 사무소 저녁 — 충동적 결심·엘리베이터

- **위치/공간:** 사무소 저녁. 퇴근 직전. 한율이 민원 목록을 덮고 가방을 든 것.
- **직전 전환(브릿지 — 직전 회차에서의 전환):**
  - 유형: 시간 점프(31화 오후→32화 저녁 퇴근 직전).
  - 건너뛴 폭: 오후 중.
  - 이동 동기: 31화 "더 이상 앉아 있기가 어려웠다"는 충동의 저녁 이행.
  - 도입 좌표: 어디(사무소 저녁)·언제(퇴근 직전)·누구(한율·가방 든 채)·왜(802호←702호로 가는 충동).
  - 상태 연속성: 31화 감동 절단 서미정 거울→충동 이행. 온도차: 내면 자각→행동 전환(아직 어색함).
- **등장:** 한율(주·충동 결심), 상경(짧게·배경·퇴근 인사).
- **장면 목표:** 한율이 가방을 들고 퇴근하려다 충동적으로 방향을 바꿔 304동 엘리베이터 쪽으로 걷는 것 — 분류표도 답변서도 없이.
- **장애물/어긋남(§1-C §2 오판 변주):** 상경이 "어, 한율씨 집이 저쪽 아닌데요?" 하는 것 — 한율이 "잠깐요"라고만 하고 가는 것. 상경이 뭔지 모르면서 엄지를 들어주는 낙차. ★이 화의 C형 군불이 아닌 일상 잽.
- **관계 압박/정서적 긴장:** 엘리베이터에 타면서 한율이 가방 안을 확인하는 것 — 아무것도 없다. 분류표 없고 답변서 없고 법조항 없음. '이렇게 가는 게 맞는 건지'라는 막막함.
- **핵심 행동:** 퇴근 방향 전환(충동) → 304동 엘리베이터 탑승 → 7 버튼 누름.
- **감정 비트 흐름:** 퇴근 결심(어색한 충동) → 방향 전환(작은 용기) → 엘리베이터 안 속말(서미정 거울 완성).
- **씨앗/회수:** ★[엘리베이터 안 서미정 거울 완성] 한율이 7층으로 올라가는 동안의 속말 — "아무것도 안 들고 왔다. 분류표도 답변서도. 그냥 들으러 왔다는 게 말이 되는 건지도 모르면서." 31화의 "나도 잠깐 앉았다 갈 사람인데"에서 이어지는 흐름. 서미정 거울 정서 2차 완성. 서미정 이름 0.
- **웃음 비트:** 상경이 "어, 한율씨 집이 저쪽 아닌데요?" → 한율 "잠깐요" → 상경이 뭔지 모르면서 엄지 드는 것 → 엘리베이터 닫히는 것 — 상경의 엄지가 문에 끊기는 장면.
- **장면 종료 이미지:** 엘리베이터 버튼 '7'이 눌려 있다. 올라가는 중.

### 〔씬 2〕 304동 702호 문 앞 — 문을 두드리지 못하다

- **위치/공간:** 304동 702호 문 앞. 저녁. 복도 형광등 켜진 곳.
- **직전 전환(브릿지):**
  - 유형: 현실 이동(엘리베이터 도착→복도).
  - 건너뛴 폭: 없음(연속).
  - 도입 좌표: '7층에서 내렸다'.
  - 상태 연속성: 엘리베이터 속말→702호 문 앞 도달. 온도차: 내면 속말→실제 행동 직전의 긴장.
- **등장:** 한율(주·문 앞·멈춤). 배경에 복도 조용함.
- **장면 목표:** 한율이 702호 도어벨 앞에 서서 누르지 못하는 것 — 이유를 정확히 모른 채. 속말로 '무슨 말을 할지 모른다'는 것.
- **장애물/어긋남:** 벨을 누르려는데 '뭐라고 할 건데'라는 생각이 먼저 오는 것 — 답변서 없이, 근거 없이, 조항 없이 '그냥 들으러 왔습니다'가 말이 되는가. 한율이 이것을 처리하지 못함.
- **관계 압박/정서적 긴장:** 702호 문이 그냥 문인데 한율에게는 '내가 못 여는 문'처럼 느껴지는 것 — 숫자로는 다 풀었는데 이 문 하나를 못 두드리는 역설.
- **어긋나면 걸리는 것:** 지금 돌아서면 오늘 여기까지 온 것이 '아무것도 안 한 것'이 됨. 그러나 두드리지 못하면 그것도 사실.
- **핵심 행동:** 702호 앞에 섬 → 벨을 누르려다 멈춤 → 손을 내림 → 잠깐 서 있음 → 돌아섬.
- **감정 비트 흐름:** 문 앞 도달(긴장) → 멈춤(막막함) → '무슨 말 할지 모른다'(자각) → 돌아섬(허탈하지만 배운 것).
- **씨앗/회수:** [한율이 문 못 두드림] '들으러 가는 것'과 '들을 준비가 된 것'이 다르다는 것의 자각. 33화에서 실제로 들을 준비를 하고 다시 오는 것의 씨앗. [702호 문] 나중에 이 문이 열리는 장면이 감동 포인트가 됨.
- **웃음 비트:** ★없음(씬2는 조용하게). 코미디는 씬3에서.
- **장면 종료 이미지:**

```
702호.
도어벨이 오른쪽에 있었다.

손이 올라갔다가 내려왔다.

무슨 말을 할 건데.
그 생각이 먼저였다.
아무것도 없었다. 분류표도 답변서도.
그냥 들으러 왔다는 게 말이 되는 건지도 모르면서.

한율이 돌아섰다.
```

### 〔씬 3〕 엘리베이터·1층 — 고만옥과 마주침

- **위치/공간:** 엘리베이터 내려오는 길·1층. 고만옥과 마주치는 곳.
- **직전 전환(브릿지):**
  - 유형: 현실 이동(702호 문 앞→엘리베이터 귀환).
  - 건너뛴 폭: 없음.
  - 도입 좌표: '내려가는 엘리베이터 안'.
  - 상태 연속성: 씬2 허탈함→귀환. 온도차: 조용한 허탈→고만옥의 갑작스런 밝음(온기 전환).
- **등장:** 고만옥(입주민·온기·따뜻한 충격), 한율(주·설명 어려운 상황).
- **장면 목표:** 고만옥이 같은 엘리베이터에 타거나 1층에서 만나 "어디 갔다 와요?" 묻는 것 — 한율이 "702호…"라고 했다가 "아뇨, 그냥 지나쳤어요"로 말을 바꾸는 낙차. 고만옥이 "702호면 영자씨?" 하며 아는 척 하는 것.
- **장애물/어긋남:** 고만옥이 "영자씨 요즘 왜 그래요, 전에는 안 그랬는데"라고 무심히 말하는 것 — 한율이 '전에는 안 그랬다'를 박만수에 이어 두 번째로 듣는 것. '왜 변했는가'의 힌트가 쌓임.
- **관계 압박/정서적 긴장:** 고만옥이 백영자를 '영자씨'라고 부르는 것 — 민원인이 아니라 이름으로 부르는 사람이 있다. 한율이 그것을 처음으로 듣는 순간.
- **핵심 행동:** 고만옥 마주침 → 한율 설명 시도→수정 → 고만옥 "영자씨 전에는 안 그랬는데" → 한율 듣기.
- **감정 비트 흐름:** 허탈 귀환 → 고만옥 갑작스런 밝음(온기 환기) → "영자씨" 호칭 낙차(작은 충격) → "전에는 안 그랬는데" 두 번째 힌트(쌓임).
- **씨앗/회수:** [고만옥 "영자씨"] 백영자가 이름으로 불리는 사람임의 첫 확인. [두 번째 "전에는 안 그랬다"] 박만수+고만옥 = 두 사람이 같은 말을 한다는 것. 33화 이면 발견의 직접 복선.
- **웃음 비트(★코미디 핵):** 고만옥이 "702호 갔다 왔어요?" → 한율이 "아뇨… 그냥 지나쳤어요" → 고만옥: "7층에서 지나쳐요?" → 한율: "…네." → 고만옥이 잠깐 한율을 보다가 "옥수수 좀 쪄놨는데 드릴게요" 하며 손을 이끄는 것 — 논리적으로 전혀 연결이 안 되는 옥수수 제안. 한율이 '이 분위기에서 어떻게'라고 생각하면서도 따라가는 낙차. ★고만옥 옥수수 = 백영자 옥수수 씨앗의 변주.
- **장면 종료 이미지:** 고만옥이 한율의 손목을 가볍게 이끌며 "밥은 먹었어요?" 하고 걷기 시작한다.

### 〔씬 4〕 고만옥 집 앞·평상 — 코미디 온기 + 처음의 전환

- **위치/공간:** 단지 평상 또는 고만옥 집 현관 앞. 봄 저녁. 옥수수 한 개.
- **직전 전환(브릿지):**
  - 유형: 장소 이동(엘리베이터→평상·현관 앞).
  - 건너뛴 폭: 없음.
  - 도입 좌표: '평상 앞이었다'.
  - 상태 연속성: 씬3 고만옥 이끌림→평상 도착. 온도차: 온기 지속.
- **등장:** 고만옥(온기·옥수수·단지 정), 한율(주·받는 쪽·처음의 전환).
- **장면 목표:** 고만옥이 옥수수를 건네며 "영자씨가 어릴 때부터 여기 살았어요"라는 한마디를 흘리는 것 — 백영자가 이 단지에 아주 오래 산 사람임의 첫 공개. 한율이 옥수수를 먹으며 처음으로 '들어야 한다'를 이해하기 시작.
- **장애물/어긋남:** 한율이 "영자 씨가 왜 민원을 그렇게 많이 내는 거예요?"라고 묻자 고만옥이 "글쎄요, 나도 몰라요"라고 말하는 것 — 박만수도 모르고 고만옥도 모른다. 모르는 사람이 두 명째. '모르는 게 아니라 아직 물어본 사람이 없는 건지도'.
- **관계 압박/정서적 긴장:** 고만옥이 "그냥 외로운 사람이에요, 우리 영자씨"라고 무심히 말하는 것 — 한율이 이것을 처음으로 듣는 순간. '몇백 원 때문이 아니라'라는 백영자의 말과 겹침. 아직 전부가 연결되지는 않았지만.
- **어긋나면 걸리는 것:** 지금 이 말을 흘려들으면 33화에서 백영자를 다시 만날 수 없다.
- **핵심 행동:** 고만옥 옥수수 건넴 → "영자씨 어릴 때부터 여기" → 한율 "왜 민원을" → "나도 몰라요, 그냥 외로운 사람이에요" → 한율 처음으로 '들어야 한다' 이해 시작.
- **감정 비트 흐름:** 옥수수 온기(코미디 이후 따뜻함) → "어릴 때부터" 정보(새로운 층위) → "그냥 외로운 사람"(핵 개방) → 한율 처음의 이해.
- **씨앗/회수:** [고만옥 "그냥 외로운 사람이에요"] 백영자 이면 핵(외로움)이 처음으로 직접 언급됨. 33화에서 한율이 들으러 가는 것의 결정적 씨앗. [옥수수] 고만옥→백영자→한율로 이어지는 옥수수 연결. 38화 화해 씨앗 한 층 더.
- **웃음 비트:** 고만옥이 옥수수를 건네며 "이거 드세요, 이 단지에서 외로운 사람은 옥수수 먹으면 조금 나아요"라고 진지하게 말하는 것 — 한율: "…그게 무슨 원리예요?" 고만옥: "몰라요, 그냥 그래요." 한율이 그것을 먹기 시작하는 것.
- **장면 종료 이미지·코미디 엔딩:**

```
옥수수가 달았다.
```

## 4. 정서·재미 장치

- **자료 없이 선 한율(D형 핵심 장면):** 한율이 처음으로 숫자·분류표 없이 행동하는 장면 — 이것이 성장의 시작. 문을 못 두드리는 것이 실패가 아니라 '들을 준비가 무엇인지 처음 배우는 것'.
- **고만옥의 논리 점프 코미디:** "7층에서 지나쳐요?" → "옥수수 드릴게요" — 논리 연결 없는 고만옥의 자연스러운 챙김이 코미디 핵.
- **"그냥 외로운 사람이에요"(이면 핵 첫 직접 발화):** 고만옥의 무심한 한마디가 이 화의 가장 중요한 정보. 설명 없이 그냥 흘림.
- **옥수수 이미지 누적:** 박만수(31화 씨앗)→고만옥(32화 실물)→백영자(38화 화해). 소품 에코 설계.
- **★서미정 거울 완성(씬1~씬2):** 엘리베이터 속말에서 완성 — "아무것도 안 들고 왔다. 그냥 들으러 왔다는 게 말이 되는 건지도 모르면서." 31화 씨앗→32화 완성. 이름 누설 0.

## 5. 따뜻한 절단

- **엔딩 타입:** 코미디 + 온기 ("다음에는 들을 준비를 하고 가야겠다" — 문을 못 두드렸지만 '들어야 한다'를 처음으로 배운 것. 웃음과 따뜻함 공존).
