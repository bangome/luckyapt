## 1. 회차 목적

- **독자에게 줄 것:** 단톡방에서 채연주의 하소연이 터지고, 830세대 단지를 혼자 떠안은 박봉 막내의 실태가 처음 드러나는 **짠함과 분노(공감)**. 한율이 처음으로 동료를 '구하러 간다'는 방향을 잡는 도화선.
- **기능(3막 1화차 = 도입·실태 파악):**
  1. **채연주 throughline 개시:** 단톡방 하소연 → 실태(830세대 혼자·야근수당 미청구·말일 마감 수계산 지옥) 첫 노출. 아직 한율이 본격 개입 전, '이게 얼마나 심각한가'를 독자가 파악하는 단계.
  2. **단톡방 '경리들모임' 무대 재등장:** 채연주·나은서·상경 단톡방 케미 (사극톤·이모티콘·분개)가 살아나며 단지 바깥 동료 네트워크가 3막의 새 무대로 열림.
  3. **정서 전환:** 18화 식구감 회복의 온기가 '한율의 시선이 채연주로 확장'되는 브릿지.
  4. **한율 응원 이유(법칙3):** 한율이 채연주 실태를 처음 보고 "이건 틀린 숫자"를 직감하는 순간 — 오늘의 응원 근거는 '실력 있는 베테랑이 틀린 걸 알아보는 것'과 '누군가를 못 지킬까 봐의 두려움'이 함께 작동.

## 2. 장면 목록

### 〔씬 1〕 저녁 사무소 — 단톡방 알림

- **위치/공간:** 관리사무소 내부, 봄 저녁. 한율이 혼자 마감 정리 중. 폰 알림 — 단톡방 「경리들모임」 채팅 화면. 물리 공간(사무소)+폰 화면 공간(단톡방) 이중 구조.
- **직전 전환(브릿지·직전 회차에서의 전환):**
  - 유형: 시간 점프(18화 합의문 그날 밤→며칠 뒤 저녁) + 초점(단지 공용공간→사무소 저녁 업무).
  - 건너뛴 폭: 며칠(18화 봄밤→19화 봄 저녁, 같은 봄 후반).
  - 이동 동기: 한율이 일상 업무를 마감하는 저녁, 18화 끝에서 '마음에 걸렸던' 채연주 쪽 알림이 드디어 뜨는 자연 전환.
  - 도입 좌표: 어디(사무소 저녁)·언제(늦봄 저녁)·누구(한율·혼자)·왜(마감 정리 중 단톡방 알림 — 채연주 첫 메시지).
  - 상태 연속성: 18화의 따뜻한 식구감 온기 뒤. 한율 마음속 '채연주 쪽 일이 마음에 걸렸다'가 현실로 오는 전환(온도차: 단지 식구감→단지 밖 동료의 하소연).
- **등장:** 한율(주·발신자), 채연주(단톡방·하소연 시작), 나은서(단톡방·첫 반응).
- **장면 목표:** 채연주의 첫 메시지가 단톡방에 올라오는 것을 한율이 발견하고, 처음엔 '또 愚痴(넋두리)인가' 싶다가 내용을 읽으며 긴장하는 것.
- **장애물/어긋남(한율 오판·문화충격):** 채연주의 하소연 첫 줄은 "제가 잘못하는 건지도 모르겠어여ㅠㅠ" — 한율은 처음에 '이건 업무 미숙 문제겠지' 하고 정석 조언을 치려다, 나은서가 "잠깐만여 채연주씨 얼마 받으세여" 치고 들어와 방향이 바뀜.
- **관계 압박/정서적 긴장:** 채연주가 830세대 단지를 혼자 맡는다는 게 단톡방에서 자연히 드러남 — 나은서 "오 그거 보통 경리 두 명이 하는 단지 아니에여?" 식의 반응으로 독자도 실태를 맥락으로 파악.
- **어긋나면 걸리는 것:** 한율이 그냥 스쳐 지나치면 채연주의 미지급 수당·야근 지옥이 계속된다. 이 밤 한율이 관심을 갖는 게 3막의 씨앗.
- **핵심 행동:** 채팅 알림 확인 → 내용 읽기(한율 능동) → 나은서 반응에 채연주 추가 메시지 → 급여 문제 언급이 나오기 시작(배경 노출).
- **감정 비트 흐름:** 마감 정리 중 알림(평범) → 채연주 넋두리 톤(가볍게) → 나은서 "얼마 받으세여" 직격(흥미) → 채연주 조심스러운 답(방 공기 진지해짐) → 한율 '이건 좀 다르다' 감각.
- **씨앗/회수:** [채연주 하소연 시작·씨앗3 전단계] 830세대 혼자 + 급여 문제 언급 첫 노출. [나은서 캐릭터] 드립 대신 진지 모드로 전환하는 게 캐릭터 깊이. [단톡방 케미] 상경이 아직 반응 안 함(자리 떠남).
- **웃음 비트:** 한율이 채연주 하소연 첫 줄에 자동으로 '업무 미숙 유형 분류'를 시작하다(속말: 절차 미숙인지 계정 오류인지 먼저 분류하려는 직업병) 나은서가 전혀 다른 방향("얼마 받으세여")으로 튀어나오는 격의 낙차. ★가볍게.
- **단톡방 규약(★style_policy §2):** 애교체 허용(채연주 ~여·이모티콘·나은서 사극톤), ㅋㅋ/ㅠㅠ 기호 자체는 묘사로 처리('채연주가 울먹이는 이모티콘을 길게 연타했다'), 한율 채팅 정확체.
- **장면 종료 이미지:** 한율이 폰을 내려다보며 숫자 한 줄이 언급되는 것을 읽는다. 〔속말〕 *아직 모른다. 하지만 이 방향이 맞는지 먼저 확인해야 한다.*

### 〔씬 2〕 단톡방 — 채연주 실태 파악

- **위치/공간:** 폰 화면(단톡방). 봄 저녁~밤. 채연주의 메시지가 쌓이는 채팅 화면. 사무소 안이지만 카메라는 폰 화면에 밀착.
- **직전 전환(브릿지):**
  - 유형: 채팅↔현실 전환 (씬1에서 폰 화면으로 완전히 초점 이동).
  - 건너뛴 폭: 거의 없음(연속). 도입 좌표 = '채연주의 메시지가 계속 올라오고 있었다'.
  - 상태 연속성: 씬1의 '이건 좀 다르다' 감각을 받아 한율이 능동적으로 읽기 시작(온도차: 가벼운 단톡→진지한 실태 파악).
- **등장:** 채연주(단톡방 주·하소연), 나은서(단톡방·분개), 한율(단톡방·읽는 쪽·능동).
- **장면 목표:** 채연주가 830세대 단지를 혼자 담당하는 상황·야근수당 미청구·말일 마감 수계산 지옥의 실태를 단톡방 대화로 드러내고, 한율이 '숫자를 바로 봐야 한다'고 판단하기 시작하는 것.
- **장애물/어긋남:** 채연주는 "제가 부족해서 이런 거 아닐까여ㅠㅠ"로 자기 탓으로 돌리는 패턴을 보여줌 — 한율이 속으로 그 자책을 정면으로 반박하고 싶은데, 아직 숫자를 보기 전이라 단정할 수 없다는 직업적 자제.
- **관계 압박/정서적 긴장:** 나은서 "슨배림… 이거 그냥 뒤나요 아니면 진짜 문제인 거에요?" — 한율에게 직접 물음. 한율이 답할 수 없는 상태(아직 숫자를 안 봄). 채연주가 "제가 할게요" 반사로 모든 걸 다 끌어안고 있었다는 게 드러남.
- **어긋나면 걸리는 것:** 한율이 "일단 숫자 보내줘요"라고 하지 않으면 채연주의 억울함은 넋두리로 끝난다.
- **핵심 행동:** 채연주 실태 메시지 다수(830세대·야근·수당 미청구·말일 마감 겹침 설명) → 나은서 분개 → 한율이 "급여명세서 보낼 수 있어요?"라고 처음 능동 개입.
- **감정 비트 흐름:** 채연주 하소연(짠함·공감) → 나은서 분개 드립(웃음+분개) → 채연주 자책(더 짠함) → 한율 '이건 숫자 문제다' 직감 → "급여명세서 보내줄 수 있어요?" 능동 개입(전환).
- **씨앗/회수:** [채연주 아크 씨앗3] 미지급 야근수당의 실태가 처음으로 구체화. [나은서↔한율 케미] "슨배림 진짜 문제인 거에요?"—한율이 정확체로 "봐야 압니다"라고 치면 방이 잠시 조용해지는 긴장(정확체가 여기선 진지함으로 작동). [채연주 자책 씨앗] "제가 부족해서"→후반 "그건 제 잘못이 아니었네요" 회수 예고.
- **웃음 비트(단톡방):** 나은서 사극톤 "그 단지 경리 수는 몇이온지요"(분개를 사극톤으로 감싸는 게 오히려 더 진지하게 만드는 역설) + 채연주 이모티콘 폭격으로 방이 잠깐 가벼워졌다가 한율 정확체에 다시 진지해지는 온도차 개그. ★단톡방 기호 직접 노출 0·묘사로.
- **장면 종료 이미지:** 채연주가 급여명세서 이미지를 찍어 올리기 직전, "지금 찍어도 될까여…(수줍음)(사랑)" 하고 머뭇거리는 메시지. 한율이 그것을 기다리며 폰을 든다.

### 〔씬 3〕 사무소 — 급여명세서 첫 확인

- **위치/공간:** 사무소 책상, 봄 밤. 한율이 폰으로 받은 채연주 급여명세서 이미지를 확인. 폰 화면과 한율의 반응.
- **직전 전환(브릿지):**
  - 유형: 채팅↔현실 전환(폰 화면→한율 현실 반응·손의 정지).
  - 건너뛴 폭: 없음(채연주가 사진 올린 직후).
  - 도입 좌표: '화면에 이미지 하나가 떴다. 급여명세서였다.'
  - 상태 연속성: 씬2의 '기다림'에서 바로 이어짐. 온도차: 기다림→손이 멈추는 발견.
- **등장:** 한율(주·확인·손이 멈춤), 채연주(단톡·기다리는 중), 나은서(단톡·"슨배림 뭐예여?").
- **장면 목표:** 급여명세서를 처음 본 한율이 '이건 틀렸다'를 숫자로 파악하는 것. 서스펜스 엔딩의 핵심 장면.
- **장애물/어긋남:** 명세서에 수당 항목이 비어 있거나 기재 방식 자체가 이상 — 한율 입장에서 '야근수당을 청구 안 한 게 아니라 애초에 부과 자체가 설계되지 않은 구조'일 수 있다는 직감(구체 계산은 20화).
- **관계 압박/정서적 긴장:** 채연주가 "제가 원래 이렇게 받는 거 맞는 거 아닌가여ㅠㅠ"라고 메시지를 보냄 — 한율이 그 메시지를 읽으며 가슴이 한 번 굳는다(못 지킬까 봐의 두려움).
- **어긋나면 걸리는 것:** 이 숫자가 틀린 걸 아무도 말해주지 않으면 채연주는 "내가 부족해서"로 계속 자책한다.
- **핵심 행동:** 급여명세서 이미지 확인(한율 능동) → 수당 항목 훑기(전문가의 빠른 시야) → 손이 멈추는 장면(03 §1-C §3 '숫자의 이상 징후=손이 멈추는 장면').
- **감정 비트 흐름:** 이미지 열기(집중) → 훑기(점점 빨라지는 서술) → 어떤 항목에서 손이 멈춤(서스펜스 정점) → 채연주 "맞는 거 맞죠여…?" 메시지가 동시에 뜸(짠함).
- **씨앗/회수:** [숫자의 이상 징후] 구체 수치는 20화로 슬로번. 19화는 '무언가 잘못됐다'는 감각까지. [채연주 자책 메시지] 후반 "그건 제 잘못이 아니었네요" 회수 예고.
- **웃음 비트:** ★없음(손이 멈추는 서스펜스 장면·웃음 미룸).
- **장면 종료 이미지:** 한율이 급여명세서를 확대해 한 항목을 손가락으로 짚는다. 밖에서 나은서가 "슨배림 뭐예여 왜 조용하오" 쳤다. 한율은 그 메시지를 보지 못했다.

### 〔씬 4〕 단톡방 / 사무소 — 서스펜스 절단

- **위치/공간:** 폰 화면+사무소 책상. 봄 밤 늦게. 한율이 채연주에게 첫 메시지를 치기 직전.
- **직전 전환(브릿지):**
  - 유형: 시간 미세 점프(씬3 직후·몇 분 뒤) + 채팅↔현실.
  - 건너뛴 폭: 몇 분(한율이 확인 후 생각하는 시간).
  - 도입 좌표: '한율이 잠시 화면을 꺼뒀다가 다시 켰다'.
  - 상태 연속성: 씬3의 '손이 멈춤'에서 이어지는 한율의 능동 개입 결심.
- **등장:** 한율(주), 채연주(단톡), 나은서(단톡).
- **장면 목표:** 서스펜스 엔딩 — 한율이 "내일 확인해야 할 게 있어요"라고 치면서, 독자(와 채연주)에게 '이제 뭔가 시작된다'는 기대를 남기는 절단.
- **장애물/어긋남:** 아직 전체 그림을 모르는 상태에서 채연주에게 섣부른 말을 해선 안 된다는 직업적 자제(사이다는 숫자 확인 후에 해야 한다—한율의 원칙). "잘못됐다"고 바로 말하고 싶은 충동 vs 확인 전까지 단정 못 하는 프로의 자제.
- **관계 압박/정서적 긴장:** 채연주가 "혹시… 제가 뭔가 잘못한 건 아니죠여ㅠㅠ" 하고 다시 자책 모드로 돌아오는 메시지를 보냄. 한율이 그 질문에 바로 답해줄 수 없는 답답함.
- **어긋나면 걸리는 것:** 이 밤을 그냥 넘기면 채연주의 자책이 오늘도 답 없이 쌓인다.
- **핵심 행동:** 한율이 답장을 치기 시작 → '잘못한 거 없어요'라고 치다가 지움(확인 전 단정 못 함) → 대신 "내일 몇 가지 확인할 게 있어요. 명세서 원본 있으면 더 보내줄 수 있어요?"라고 능동 요청.
- **감정 비트 흐름:** 채연주 자책 메시지(짠함) → 한율 답장 시도·지움(프로의 자제·속말) → 다른 방식으로 능동 개입("내일 확인할 게 있어요") → 채연주 "(수줍음)(사랑) 넵여…" → 나은서 "슨배림 움직이시오" (단톡 마무리 따뜻함).
- **씨앗/회수:** [3막 엔진 점화] 한율이 능동으로 채연주 수당 계산에 뛰어드는 것이 확정. [나은서 "슨배림 움직이시오"] RG-5 이방 한정 아이돌 전단계의 단톡 케미. [잔가시] 한율이 폰을 내려놓으며 속말 — 정확히 어떤 숫자가 틀렸는지는 내일 봐야 안다.
- **웃음 비트:** 나은서 "슨배림 움직이시오" + 채연주의 이모티콘 폭격 + 방이 갑자기 따뜻해지는 분위기 전환. 그러나 한율 폰 내려놓는 장면은 조용히 마무리(서스펜스 보호).
- **장면 종료 이미지·따뜻한 절단:**

```
한율이 폰을 뒤집어 책상에 엎어놓았다.
명세서 이미지는 머릿속에 남아 있었다.
저 항목 하나. 그 칸이 왜 비어 있는지, 내일 확인하면 된다.
확인하면 안다.
숫자는 거짓말을 하지 않는다.
문제는, 숫자가 맞을 때 더 화가 난다는 것이었다.
```

## 3. 사건 동선

- **물리 동선:** 사무소 저녁(씬1·2·3·4 연속) — 한율이 자리를 뜨지 않음. 단톡방이 '가상 공간'으로 사무소와 병렬 존재.
- **폰↔현실 동선:** 씬1(알림 확인·현실), 씬2(폰 화면 밀착·채팅 공간), 씬3(이미지 열람·현실 반응), 씬4(채팅 재개·능동 개입·현실로 마무리).

## 4. 정서·재미 장치

- **짠함의 진입:** 채연주 "제가 부족해서"·"맞는 거 맞죠여" — 자책형 캐릭터의 자기 비하가 독자 분노를 서서히 만듦.
- **나은서 캐릭터:** 사극톤 분개("그 단지 경리 수는 몇이온지요")가 웃음이면서 동시에 진짜 분개. 드립이 가면이라는 것이 자연히 드러남.
- **한율 직업병 웃음:** 채연주 첫 메시지에 자동으로 '업무 미숙 유형 분류' 발동하다가 나은서에게 밀리는 낙차(RG-4 결).
- **서스펜스 핵:** 급여명세서 항목에서 손이 멈추는 장면 — '무엇이 비어 있는가'는 20화로 슬로번하여 서스펜스 유지.
- **법칙3 한율 응원 이유:** '이건 틀린 숫자다'를 아는 베테랑의 직감 + '못 지킬까 봐'의 두려움이 채연주를 향해 처음 발동.
- **온도차 완화:** 나은서 "슨배림 움직이시오"·채연주 이모티콘 폭격으로 서스펜스 직전 한 박자 따뜻한 온기 삽입.
