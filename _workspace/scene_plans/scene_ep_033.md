## 1. 회차 목적

- **독자에게 줄 것:** 32화에서 못 두드렸던 문을 이번엔 두드리는 것 — 한율이 처음으로 '들을 준비'를 하고 간다는 것의 작은 성취 + 백영자가 마침내 진짜 이야기를 꺼내기 시작하는 도화선. 봄 최저점의 끝자락에서 변화의 첫 빛.
- **기능(4막 5화차 — 702호 문 두드리기·백영자 발화 시작):**
  1. **들을 준비:** 한율이 오전에 '들을 준비'란 무엇인지 생각하는 것 — 분류표도 답변서도 아닌 것. 빈 노트 한 권을 가지고 가기로 결심.
  2. **702호 문을 두드림:** 이번엔 벨을 누른다. 백영자가 문을 열어준다 — 예상과 다른 첫 반응(쫓아내지 않는다).
  3. **백영자의 집 안:** 한율이 처음 백영자의 집에 들어가는 것 — 집 안의 분위기·물건들이 백영자라는 사람을 조금 더 열어줌. 말을 시작하기 전의 공간.
  4. **백영자 발화 시작:** "내가 처음 민원 낸 게 언제인지 알아요?" — 백영자가 먼저 말을 시작한다. 한율이 드디어 들을 준비가 된 사람임을 백영자도 느낀다. 서스펜스로 절단.

## 2. 독자 추적 가이드

- **이번 회차의 표면 상황:** 한율이 빈 노트를 들고 702호 문을 두드린다. 백영자가 처음으로 진짜 이야기를 꺼내기 시작한다.
- **독자가 따라갈 핵심 축(최대 3):**
  1. 한율이 이번엔 문을 두드릴까 (32화 미완의 회수)
  2. 백영자가 문을 열어줄까, 무슨 말을 할까
  3. 백영자의 집 안이 어떤 사람의 공간인가
- **숨겨도 되는 정보:** 백영자의 구체적 사연 전모(34화 공개).
- **반드시 이해시킬 '걸린 것':** 한율이 이번에도 준비 없이 가면 백영자는 다시 문을 닫는다. 한율이 처음으로 '들을 준비'를 선택해야 한다.
- **누구의 마음을 따라가나(초점 인물):** 한율(32화 충동의 이행·두려움·선택).
- **마음의 거리·어긋남의 출처:** 문을 두드리는 것과 들을 준비가 된 것은 다르다 — 한율이 그 차이를 몸으로 느끼는 것.
- **누군가의 작은 행동(회복의 씨앗):** 한율이 빈 노트를 꺼내는 것 / 백영자가 쫓아내지 않고 문을 열어주는 것.
- **풀리는 순간(뭉클 또는 웃음):** 백영자가 "들어와요"라고 말하는 순간 — 작고 조용한 변화.
- **풀린 뒤 남길 작은 그늘:** 백영자가 아직 다 말하지 않았다. 도화선만 켜졌다.

## 3. 장면 목록

### 〔씬 1〕 사무소 오전 — '들을 준비'를 만드는 시간

- **위치:** 사무소 오전. 한율 데스크. 민원 목록은 서랍 안에 들어가 있음.
- **시간대:** 봄 아침 늦은 시간(9시 이후). 사무소가 정리되어 조용한 시간.
- **시간대 기능:** 새 시작·결심의 시간.
- **시간대 감각 단서:** 창문으로 봄 햇빛. 상경이 아직 민원 응대 중 아닌 조용한 틈. 커피 냄새.
- **공간 구조:** 데스크. 서랍 안의 민원 목록. 빈 노트(새것·아직 아무것도 적히지 않은).
- **직전 장면과의 전환(브릿지 — 직전 회차에서의 전환):**
  - 유형: 시간 점프(32화 봄 저녁 옥수수 평상 → 33화 다음 날 아침 사무소).
  - 건너뛴 폭: 하룻밤. 한율이 옥수수를 들고 단지를 걸은 뒤 집으로 돌아가 생각한 것.
  - 이동 동기: '들을 준비'가 무엇인지 밤새 생각하다 사무소로 출근한 것.
  - 도입 좌표: 어디(사무소 오전·한율 데스크)·언제(봄 아침)·누구(한율 혼자)·왜(들을 준비를 만들어야 한다).
  - 상태 연속성: 32화 코미디 절단의 "들을 준비" 다짐 이행. 온도차: 옥수수 따뜻함→고요한 결심.
- **등장 인물:** 한율(주·결심), 상경(배경·짧게).
- **장면 목표:** 한율이 '들을 준비'가 무엇인지를 구체화하는 것 — 조항이 아니라 말의 순서를 생각하는 것. 빈 노트를 가져가기로 결심.
- **독자용 표면 목표:** 한율이 이번엔 뭘 가지고 702호로 갈 것인가.
- **장애물/어긋남:** 상경이 "한율씨 오늘 또 야근 남을 것 같아요?"라고 무심히 묻는 것 — 한율이 "아니요, 일찍 나갈 것 같아요"라고 답하자 상경이 "어, 처음 들어봐요"라며 약간 놀라는 낙차(한율이 야근 외에 다른 결정을 내린 것의 신호).
- **관계 압박/정서적 긴장:** 한율이 서랍에서 민원 목록을 꺼낼까 말까 하다가 — 결국 꺼내지 않는 것. 대신 빈 노트를 꺼내는 것.
- **어긋나면 걸리는 것:** 분류표를 들고 가면 또 같은 실패. 빈 노트를 들고 가는 것이 이번 화의 선택.
- **핵심 행동:** 서랍 열기 → 민원 목록 꺼낼까 멈춤 → 서랍 닫기 → 책상 한구석의 빈 노트 꺼내기 → 가방에 넣기.
- **감정 비트 흐름:** 조용한 결심(집중) → 서랍 열고 닫기(선택의 순간) → 빈 노트 선택(작은 용기) → 상경과 짧은 교차(웃음 완충).
- **씨앗/회수:** [빈 노트] 34화에서 한율이 백영자의 말을 처음으로 '조항 없이' 받아 적기 시작하는 것의 소품. [민원 목록 서랍에 넣기] 분류표가 사라지는 상징 — 한율의 방식이 바뀌기 시작함.
- **웃음 비트:** 한율이 가방에 빈 노트를 넣으며 "뭐 든 노트 아닌가요?"를 속으로 생각하는 것. 상경이 "한율씨, 오늘 점심은 어디 드실 거예요?"라고 묻자 "저 잠깐 나갔다 올게요"라고만 하고 나가는 것 — 상경이 나가는 한율 뒤를 멀뚱히 보는 장면.
- **장면 종료 이미지:** 한율이 가방을 들고 사무소를 나선다. 봄 햇빛이 복도에 가득하다.

### 〔씬 2〕 304동 엘리베이터 → 7층 복도 — 이번엔 문을 두드린다

- **위치:** 304동 엘리베이터 → 7층 복도 → 702호 문 앞.
- **시간대:** 봄 낮 (점심 전).
- **시간대 기능:** 일과 중 이탈·결심의 실행.
- **시간대 감각 단서:** 복도 형광등. 조용한 낮 시간. 세탁기 돌아가는 소리 어딘가에서.
- **공간 구조:** 엘리베이터 버튼 '7'. 7층 복도. 702호 문 앞 도어벨.
- **직전 전환(브릿지):**
  - 유형: 장소 이동(사무소 → 304동 엘리베이터).
  - 건너뛴 폭: 없음(연속).
  - 도입 좌표: '304동 엘리베이터 앞에 왔다'.
  - 상태 연속성: 씬1 결심→실행. 온도차: 조용한 내면→실제 이동의 긴장.
- **등장 인물:** 한율(주·긴장·선택).
- **장면 목표:** 한율이 32화와 같은 자리에 다시 선다 — 이번엔 손이 올라간다. 벨을 누른다.
- **독자용 표면 목표:** 이번엔 문을 두드릴까? (32화 미완의 회수).
- **장애물/어긋남:** 엘리베이터 안에서 한율이 가방 안 빈 노트를 한 번 더 확인하는 것 — 32화에서 "무슨 말을 할 건데"가 먼저였다면, 이번엔 "들으러 왔다"는 한 줄만 있으면 된다는 것을 스스로에게 확인하는 과정.
- **관계 압박/정서적 긴장:** 7층에서 내렸을 때 702호 문이 보이는 것 — 32화의 '손이 올라갔다 내려왔다'가 독자에게 기억되는 순간. 이번엔 손이 올라가고, 잠깐 멈추지만, 내려오지 않는다.
- **어긋나면 걸리는 것:** 또 돌아서면 백영자와의 벽은 끝내 안 열린다.
- **핵심 행동:** 7층 복도 걷기 → 702호 앞 멈춤 → 손이 올라감 → 잠깐 멈춤 → 벨을 누름 → 기다림.
- **감정 비트 흐름:** 복도 걷기(긴장 상승) → 멈춤(32화 데자뷔) → 벨 누름(작은 용기) → 기다림(정적·두근거림).
- **씨앗/회수:** [벨을 누르는 것] 32화의 '문을 못 두드린 것'의 직접 회수 — 독자가 기다린 장면. [기다리는 정적] 백영자가 문을 열 것인지 불확실한 긴장이 따뜻한 도화선.
- **웃음 비트:** 한율이 속으로 '분류표 없다, 답변서 없다, 조항 없다, 다 없다. 노트 있다. 노트. 빈 노트.'를 속으로 확인하는 것 — 베테랑 경리의 체크리스트 버릇이 엉뚱한 방향으로 발동되는 격의 낙차.
- **장면 종료 이미지:** 벨 소리. 안에서 발소리. 문이 열린다.

### 〔씬 3〕 702호 안 — 백영자의 집·처음의 공간

- **위치:** 702호 실내. 거실 소파 앞 작은 탁자.
- **시간대:** 봄 낮. 창문으로 빛이 들어오는 거실.
- **시간대 기능:** 첫 만남이 아닌 첫 '들어옴'의 공간.
- **시간대 감각 단서:** 봄 빛. 오래된 가구. 작은 화분 하나. 탁자 위 물컵.
- **공간 구조:** 오래된 아파트 거실. 소파 두 개 마주보기. 탁자 위 물컵. 벽에 오래된 사진 액자 하나(흐릿하게만). TV는 꺼져 있음. 오래 살아온 사람의 공간.
- **직전 전환(브릿지):**
  - 유형: 현실 이동(702호 문 앞→실내).
  - 건너뛴 폭: 없음.
  - 도입 좌표: '백영자가 "들어와요"라고 말했다'.
  - 상태 연속성: 씬2 긴장·기다림→문이 열리는 순간. 온도차: 복도 긴장→집 안의 조용한 낯섦.
- **등장 인물:** 백영자(주민·76세·단호·오래 살아온 공간의 주인), 한율(주·처음 들어온 사람).
- **장면 목표:** 한율이 처음으로 백영자의 집에 들어가는 것. 백영자가 쫓아내지 않는다 — 한율이 이번엔 다르다는 것을 백영자도 느낀다. 말 없는 준비가 전달되는 순간.
- **독자용 표면 목표:** 백영자가 한율을 받아줄까? 집 안은 어떤 공간인가?
- **장애물/어긋남:** 한율이 자리에 앉아 빈 노트를 꺼내자 백영자가 "또 그거예요?" 하고 묻는 것 — 한율이 "이건 비어 있어요"라고 짧게 답하는 것. 백영자가 잠깐 한율을 보는 것.
- **관계 압박/정서적 긴장:** 백영자가 물을 한 잔 가져오는 것 — 쫓아내는 사람이 물을 가져오지는 않는다. 한율이 그것을 받아 드는 것. 두 사람 사이 공기가 처음으로 조금 달라지는 순간.
- **어긋나면 걸리는 것:** 한율이 지금 조항을 꺼내거나 질문 목록을 읽으면 백영자는 다시 닫는다.
- **핵심 행동:** 백영자 "들어와요" → 한율 들어가 앉기 → 빈 노트 꺼냄 → 백영자 "또 그거요?" → 한율 "이건 비어 있어요" → 백영자 물 가져다 주기 → 두 사람 잠깐 마주 앉음.
- **감정 비트 흐름:** 문이 열리는 순간의 안도(작은 기쁨) → 집 안 공간 낯섦(관찰) → 빈 노트 교환(처음으로 달라지는 공기) → 물 한 잔(작은 변화 신호).
