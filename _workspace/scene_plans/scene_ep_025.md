## 1. 회차 목적

- **독자에게 줄 것:** 검증표 전달→채연주 소장 제시 과정의 **연대 사이다 진행** + 그 과정에서 채연주 단지 자료를 들여다보다 '이름이 좀 다르네요'라는 **미스터리 첫 감각의 서스펜스 엔딩**. 웃음과 온기 뒤에 찜찜한 잔가시.
- **기능(3막 7화차 = 검증표 전달 + 위화감 씨앗):**
  1. **검증표 전달 과정:** 한율이 단톡방으로 검증표를 공유하고, 채연주가 소장에게 제시하는 과정을 돕는 것 — 채연주가 처음으로 '내가 요구할 수 있다'는 감각을 얻는 비트.
  2. **나은서 단톡 케미:** 나은서가 검증표를 받고 자기 단지에도 써보는 코미디 잽.
  3. **위화감 1톨(★):** 한율이 채연주 단지 자료를 들여다보다 잡수입 항목명이 행운아파트와 다르게 기재돼 있는 것을 발견 — 총액은 맞는데 이름이 다름. '돈이 틀린 게 아니라 이름이 틀리다' 첫 감각.
  4. **서스펜스 엔딩:** 위화감 한 톨로 닫기 — 26화 합법 예산 처리 사이다와 연결.

## 2. 장면 목록

### 〔씬 1〕 사무소 아침 — 검증표 단톡 공유

- **위치/공간:** 사무소 아침. 봄 후반. 한율이 단톡방에 검증표를 공유하는 장면으로 열림.
- **직전 전환(브릿지·직전 회차에서의 전환):**
  - 유형: 시간 점프(24화 오후→25화 다음 날 아침).
  - 건너뛴 폭: 하룻밤.
  - 이동 동기: 전날 '소장 제시 방법'을 고민한 뒤, 먼저 검증표를 채연주에게 공유하고 적용 방법을 알려주기로 결심.
  - 도입 좌표: 어디(사무소 아침)·언제(봄 후반)·누구(한율)·왜(단톡방에 검증표 공유).
  - 상태 연속성: 24화 반전 절단('맞는 답을 만들었다. 먹히는 답은 따로 있었다') 뒤 능동 해결로. 온도차: 반전의 막막함→아침 실행.
- **등장:** 한율(주·공유), 채연주(단톡·받는 쪽), 나은서(단톡·즉시 반응).
- **장면 목표:** 검증표 공유 + 채연주·나은서 반응 — 채연주가 처음으로 '이 도구가 있으면 내가 더 빨리 끝낼 수 있다'는 것을 파악하는 것.
- **장애물/어긋남:** 채연주가 "이게 어떻게 쓰는 거예여?" 하는 것 — 엑셀 검증표 사용법을 한 번에 이해하기 어려운 초보 경리의 현실. 한율이 '설명이 필요하다'는 것을 파악.
- **관계 압박/정서적 긴장:** 나은서가 "어 이거 저희 단지도 쓸 수 있소이다!! 슨배림 감사하오이다"라며 즉시 구현을 시작하는 반응 vs 채연주의 "이게 어떻게 쓰는 거예여…(수줍음)" — 나은서가 더 빠르게 받아들이는 것과 채연주가 아직 어리둥절한 것의 대비가 채연주의 처우 현실을 보여줌.
- **핵심 행동:** 검증표 파일 단톡 공유(능동) → 나은서 즉시 반응 → 채연주 "어떻게 쓰나요" → 한율 사용법 설명 시작.
- **감정 비트 흐름:** 공유(집중·능동) → 나은서 폭발 반응(웃음) → 채연주 어리둥절(짠함·현실) → 한율 설명 준비.
- **씨앗/회수:** [나은서 즉시 구현] 나은서의 '일잘러' 면모 + 채연주와의 처우 현실 대비. [채연주 "어떻게 쓰나요"] 박봉·야근 속에서 도구마저 제대로 못 배운 환경.
- **웃음 비트:** 나은서가 검증표 받자마자 "이미 저장했소이다. 필드값 바꾸는 중이오이다"라고 치는 속도. 채연주 "저도요여" 1초 뒤. 한율 속말: *나은서씨는 이미 쓰고 있다.*
- **장면 종료 이미지:** 한율이 사용법 설명 메시지를 길게 치기 시작한다.

### 〔씬 2〕 단톡방 — 채연주 소장 제시 코칭

- **위치/공간:** 폰 화면(단톡방). 봄 오전. 한율이 채연주에게 소장 제시 방법을 코칭하는 단톡 교환.
- **직전 전환(브릿지):**
  - 유형: 채팅↔현실 전환(폰 화면 밀착).
  - 건너뛴 폭: 없음(연속).
  - 도입 좌표: '채연주의 질문이 이어졌다'.
  - 상태 연속성: 씬1의 사용법 설명이 구체적 코칭으로 심화. 온도차: 공유 흥분→실용 코칭 차분함.
- **등장:** 한율(주·코칭), 채연주(단톡·배우는 쪽), 나은서(단톡·잽).
- **장면 목표:** 한율이 채연주에게 소장에게 검증표를 어떻게 제시하는지 구체적으로 알려주는 것 — '숫자 하나로 소장을 설득하는 방법'.
- **장애물/어긋남(§1-C §2):** 한율이 "숫자를 먼저 보여주세요. 현재 야근 시간, 검증표 사용 후 예상 야근 시간. 그 차이만요"라고 조언하는데 → 채연주가 "소장님이 숫자를 잘 안 보시는 것 같아서여…" — 한율이 잠깐 멈추는 장면. '숫자가 안 먹히는 곳'이라는 현실. 한율이 다른 방법을 찾아야 하는 순간.
- **관계 압박/정서적 긴장:** 채연주가 "저 그냥 포기할게여…ㅠㅠ" 하는 순간 — 나은서가 먼저 "포기? 안 됩니다 채연주씨 거기 한번 더 해봐요"라고 분개하고, 한율이 채연주가 포기하려는 것을 직접 막는 대신 다른 경로를 제시.
- **핵심 행동:** 소장 제시 방법 코칭 → 채연주 "소장님이 숫자를 안 보신다" 장애물 → 나은서 분개 → 한율 다른 경로 제시("야근 시간이 얼마나 줄었는지를 기록으로 남겨요. 한 달치. 그게 말이 된다").
- **감정 비트 흐름:** 코칭 시작(실용) → 채연주 소장 장애물(막힘) → "포기할게여"(짠함) → 나은서 분개(웃음+분개) → 한율 대안 제시(전환).
- **씨앗/회수:** [나은서 분개] 나은서가 드립 뒤에 진심이 있다는 것 재확인. [한율 "기록으로 남겨요"] 이 기록이 나중에 26화 합법 처리의 근거가 됨.
- **웃음 비트:** 나은서 "포기라니 그건 또 뭔 말씀이오 채연주씨! 슨배림이 이렇게 고생하셨는데" → 채연주 이모티콘 폭격 → 나은서 "저 진짜 화났소이다 지금" → 한율 정확체 "화내기 전에 기록부터 만들어요" → 나은서 "…넵." ★나은서 진심 캐릭터.
- **장면 종료 이미지:** 채연주가 "…해볼게여(사랑)"라고 친다.

### 〔씬 3〕 사무소 오후 — 채연주 자료 검토 중 위화감 1톨 ★서스펜스 핵

- **위치/공간:** 사무소 오후. 한율이 채연주 단지 자료를 검토하며 기록 근거 자료를 만들어주다가.
- **직전 전환(브릿지):**
  - 유형: 채팅↔현실 전환(단톡방→사무소 책상) + 시간 점프(오전→오후).
  - 건너뛴 폭: 오전 후.
  - 도입 좌표: '오후에 한율은 채연주 단지 자료를 열었다'.
  - 상태 연속성: 씬2의 "기록 남겨요" 코칭에서 실제 기록 근거 자료 만들기로. 온도차: 단톡 온기→집중 검토·위화감 발견.
- **등장:** 한율(주·검토·발견), 채연주(단톡·자료 제공·배경).
- **장면 목표:** 채연주 단지 관리비 자료를 검토하다 잡수입 항목명이 행운아파트와 다르게 기재돼 있다는 것을 발견하는 것 — '돈은 맞는데 이름이 다르다' 첫 감각.
- **장애물/어긋남:** 위화감의 정체 — 채연주 단지 잡수입 항목명이 월에 따라 다르게 표기돼 있음(예: 어느 달은 '잡수입', 어느 달은 '임시수입', 어느 달은 '기타수입'). 총액은 비슷한데 이름이 계속 바뀜. 한율이 처음엔 '부과담당자가 서로 다른 건가'라고 해석하다가 — 패턴이 일정하지 않다는 것을 인식.
- **관계 압박/정서적 긴장:** 이 위화감은 채연주의 야근수당 문제와 직접 연결이 안 된다 — 한율이 '이건 내가 지금 볼 게 아닐 수도 있다'와 '그런데 이게 왜 자꾸 눈에 걸리는가' 사이의 긴장(직업적 본능 vs 이유 없는 의심의 자제).
- **어긋나면 걸리는 것:** 지금 이 위화감을 무시하면 나중에 '알고도 넘어갔던 것'이 된다. 그러나 지금 파고들면 채연주 문제가 옆으로 샌다.
- **핵심 행동:** 기록 근거 자료 검토(능동) → 잡수입 항목명 불일치 발견 → 손이 잠깐 멈춤(03 §1-C §3 '숫자의 이상 징후=손이 멈추는 장면') → 자료 덮기(지금은 아니다 판단).
- **감정 비트 흐름:** 검토 집중(몰입) → 항목명 불일치 발견(멈춤) → '이름이 다르다'는 감각(서스펜스 씨앗) → 자료 덮기(자제·여운).
- **씨앗/회수(★미스터리 슬로번):** [잡수입 항목명 불일치] 14화 '이름이 셋인 돈'의 채연주 단지 버전 — '돈은 맞는데 이름이 다르다' 첫 노출. 6~7막으로 슬로번. 비리 단정 0. [자료 덮기] 한율이 지금 파고들지 않는 것 — 채연주 문제 집중 유지.
- **웃음 비트:** ★없음(서스펜스 핵 보호). 씬3는 조용하고 집중적으로.
- **장면 종료 이미지:**

```
잡수입. 임시수입. 기타수입.
이달. 저달. 또 다른 달.

총액은 비슷했다. 이름만 달랐다.
한율이 자료를 덮었다.
지금은 아니었다.
```

### 〔씬 4〕 저녁 — 서스펜스 절단

- **위치/공간:** 사무소 저녁. 한율 자리·덮어둔 자료·폰.
- **직전 전환(브릿지):**
  - 유형: 시간 미세 점프(씬3 직후·저녁).
  - 건너뛴 폭: 짧게.
  - 도입 좌표: '사무소에 불이 켜졌다'.
  - 상태 연속성: 씬3의 위화감을 갖고 저녁으로. 온도차: 위화감 발견→일상 복귀·잔가시.
- **등장:** 한율(주·내면), 채연주(단톡·경과).
- **장면 목표:** 채연주가 기록을 시작했다는 단톡 메시지로 연대 온기를 받으면서, 한율은 씬3의 위화감이 마음 한켠에 남는 서스펜스 절단.
- **장애물/어긋남:** 없음 — 위화감과 온기가 공존하는 절단.
- **관계 압박/정서적 긴장:** 채연주가 "오늘부터 기록 시작했어여(사랑)(사랑)" 하고 보내옴. 한율이 그 메시지를 보며 기뻐해야 하는데, 씬3의 자료가 마음 뒤쪽에 있는 양가 상태.
- **핵심 행동:** 채연주 메시지 확인 → 짧게 답장 → 덮어둔 자료를 보는 시선.
- **감정 비트 흐름:** 채연주 메시지(따뜻·온기) → 한율 짧은 답장 → 덮어둔 자료에 잠깐 눈이 감(서스펜스 재점화) → 절단.
- **씨앗/회수:** [채연주 기록 시작] 26화 합법 처리의 준비 완료. [덮어둔 자료] 6~7막 미스터리 슬로번의 이 화 씨앗.
- **웃음 비트:** 채연주 "첫날 기록인데 이미 30분 줄었어여!!!!(사랑)(사랑)(사랑)" 이모티콘 폭격 → 나은서 "채연주씨 오늘의 사이다시오이다" → 한율 정확체 "잘 됐네요" → 나은서 "…슨배림 그렇게 짧게 기뻐하시오?" → 한율 "…정말 잘 됐네요." 방이 잠깐 웃음 → 이후 조용해지며 서스펜스.
- **장면 종료 이미지·서스펜스 절단:**

```
채연주씨가 기록을 시작했다.
그건 좋은 일이었다.

한율은 덮어둔 자료를 다시 보지 않았다.
지금은 아니었다.

하지만 잡수입. 임시수입. 기타수입.
그 이름들이 왜 계속 달랐는지는,
아직 설명이 안 됐다.
```

## 3. 사건 동선

- **물리 동선:** 사무소 아침(씬1·단톡 공유) → 폰 화면 단톡방(씬2·코칭) → 사무소 오후(씬3·위화감 핵) → 사무소 저녁(씬4·절단).
- **독자 시선 순서:** ①검증표 공유·나은서 반응(웃음) → ②채연주 소장 코칭(따뜻·장애물) → ③위화감 1톨(서스펜스 씨앗) → ④온기+잔가시(절단).

## 4. 정서·재미 장치

- **온기와 서스펜스의 공존:** 채연주 연대 사이다가 진행되는 같은 회차에 미스터리 씨앗 1톨이 얹힘 — 3막은 연대 중심이므로 서스펜스가 연대를 넘지 않게 균형.
- **나은서 진심 비트:** "저 진짜 화났소이다 지금" — 사극톤 가면 뒤에 진심이 있다는 나은서 캐릭터 깊이.
- **C형 군불 설계(★약하게):** 잡수입 항목명 불일치 = '이름이 다르다'는 감각. 식은땀 아닌 여운. 비리 단정 0. 한율이 자료를 덮는 것이 'C형 군불의 자제'를 나타냄.
- **미스터리 슬로번(★엄수):** 14화 '이름이 셋인 돈'과 결이 같지만, 14화는 행운아파트 내부(상경 잡수입 설명)이고 이번 화는 채연주 단지 자료에서 발견 — 독자에게 '이게 행운아파트만의 문제가 아닐 수도 있다'는 감각을 심되, 비리 구조 직접 노출 0.

## 5. 따뜻한 절단

- **엔딩 타입:** 서스펜스 ("그 이름들이 왜 계속 달랐는지는, 아직 설명이 안 됐다" — 채연주 기록 시작의 온기 뒤 잔가시).
- **다음 화 잔가시:** 채연주의 기록이 쌓이면 합법 처리 근거가 된다 — 26화 합법 예산 처리 사이다. + 위화감은 아직 덮어뒀다.
- **온기:** 채연주 "30분 줄었어여!!!!" 이모티콘 폭격이 서스펜스 직전 따뜻한 완충.
- **누설 가드(★엄수):** 잡수입 항목명 불일치 = '이름이 다르다'는 감각까지. '비리다' 단정 0. 둘째·도경탁·충당금·서미정 연결 0. 한율 인지 = '설명이 안 됐다' 감각까지. 독자도 모름.

## 6. prose-writer 인계 메모

- **제목:** 「봄 사무소 — 이름이 좀 다르네요」(3막 7화차).
- **★위화감 씬 설계(씬3):** 잡수입 항목명 불일치를 짧고 선명하게. '잡수입·임시수입·기타수입' — 이 세 이름이 월별로 다르게 적혀 있는 것. 총액은 비슷하다. 설명 길게 0. 한율의 '손이 멈추는 장면' 후 자료 덮기로 짧게 마무리. 비리 단정 대사·내레이션 금지.
- **★C형 군불 강도:** 식은땀 0·여운 수준. 한율이 '이상한데'가 아니라 '설명이 안 된다'는 감각으로. 독자도 '뭔가 이상하지 않나?'를 어렴풋이 느끼는 정도.
- **★나은서 코칭 씬:** 나은서가 드립 가면을 벗고 진심으로 채연주를 응원하는 것이 이번 화의 관계 보상. "저 진짜 화났소이다" 한 줄이 펀치라인.
- **분량 배분(목표 5,000~5,500자):** 씬1 ≈ 900 / 씬2 ≈ 1,400 / 씬3 ≈ 1,400(서스펜스 핵) / 씬4 ≈ 900.
- **계절 인장:** 봄 후반. 사무소 오후~저녁.
- **호칭/본명 가드:** 위장명 '한율'. 채연주 대면 0.
- **★26화 인계 훅:** 채연주 기록 시작 + 취업규칙 개정 절차 진행 + 기록 한 달치가 쌓이면 합법 처리 근거 → 26화 합법 예산 처리 사이다.
