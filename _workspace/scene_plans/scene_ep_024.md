## 1. 회차 목적

- **독자에게 줄 것:** 한율이 엑셀 수식으로 야근을 구조적으로 줄이는 방법을 설계하는 **회계 사이다 예열** — 숫자로 사람을 구하는 것이 '직접 돈을 주는 것'만이 아니라 '일하는 방식을 바꾸는 것'이기도 하다는 새로운 결.
- **기능(3막 6화차 = 엑셀 검증표 설계):**
  1. **엑셀 검증표·야근 단축 수식:** 한율이 말일 마감 수계산을 자동화할 수 있는 검증표와 수식을 설계 — 이 도구를 채연주가 쓰면 새벽 한두 시 야근이 줄어든다.
  2. **행운아파트 일상 사건 병행(5박자 §1):** 오늘의 현장 소동을 이현우 막내와의 짧은 에피소드로 처리 — 이현우의 군기 말투와 코미디.
  3. **채연주 단지 소장 문제 접근:** 검증표를 만들면서 한율이 '이 자료를 채연주가 어떻게 소장에게 제시하는가'를 고민하는 반전 포인트.
  4. **나은서 단톡 케미:** 나은서가 자기 단지 문제를 슬쩍 끼워 넣는 코미디 잽 — "슨배림 이거 저도 쓸 수 있소이다?" → 한율이 검증표를 단톡방에 공유하는 방향 힌트.

### 〔씬 2〕 사무소 — 검증표·야근 단축 수식 설계 ★중심 씬

- **위치/공간:** 사무소. 봄 오전~낮. 엑셀 집중 작업.
- **직전 전환(브릿지):**
  - 유형: 연속(씬1 직후·집중 진입).
  - 건너뛴 폭: 없음.
  - 도입 좌표: '한율이 엑셀 화면을 열었다. 이번엔 채연주 단지용이었다'.
  - 상태 연속성: 씬1의 계획 수립에서 바로 실행으로. 온도차: 잽 코미디→집중 계산.
- **등장:** 한율(주·설계), 상경(배경·가끔 끼어드는 잽).
- **장면 목표:** 말일 부과 마감 수계산을 자동화하는 검증표와 수식을 설계하는 과정 — 독자가 '이게 실제로 야근을 줄이는구나'를 체감하게 하는 회계 사이다 예열.
- **장애물/어긋남:** 설계하다 보니 채연주 단지 ERP 버전·세대 구조가 행운아파트와 달라 수식을 그대로 쓸 수 없다 — 한율이 채연주에게 단지 ERP 버전을 물어봐야 한다는 것을 파악.
- **관계 압박/정서적 긴장:** 상경이 "어머 저거 우리 거랑 다른 거 만드는 거예요?" 하고 눈치챔 → 한율 "비교 용도요" → 상경 "우리 경리는 참 부지런하다~" 하고 웃으며 넘어가는 것. 한율이 상경의 그 무심한 칭찬에 한 박자 머뭇하는 속말("…이걸 알면 어떻게 생각할까").
- **핵심 행동:** 검증표 수식 설계(능동·집중) → ERP 버전 차이 발견(장애물) → 채연주에게 확인 필요 판단 → 수식 초안 완성.
- **감정 비트 흐름:** 집중 설계(몰입·서술 가속) → ERP 버전 차이 발견(잠깐 멈춤) → 상경 무심한 칭찬(짧은 감정·속말) → 수식 초안 완성(만족).
- **씨앗/회수:** [ERP 버전 차이] 채연주 단지가 행운아파트와 구조가 다름 — 나중에 채연주 단지에서 '결이 일정치 않다' 위화감의 맥락 씨앗(25화). [상경 "참 부지런하다"] 상경이 나중에 이 일의 진짜 의미를 알게 되는 씨앗.
- **웃음 비트:** 한율이 오전 내내 집중해서 수식을 만들다가, 상경이 점심시간에 "한율씨 밥은요?" 하는 것. 한율이 시계를 보고 "…벌써요?" 하는 격의 낙차(시간 감각 상실).

### 〔씬 3〕 점심 — 단톡방 + 나은서 "저도 쓸 수 있소이다?"

  - 건너뛴 폭: 오전 작업 후.
  - 도입 좌표: '점심시간에 한율이 채연주에게 ERP 버전을 물었다'.
  - 상태 연속성: 씬2의 설계 완료→전달 준비. 온도차: 집중→단톡 온기.
- **등장:** 한율(주), 채연주(단톡), 나은서(단톡·잽).
- **장면 목표:** 한율이 채연주에게 ERP 버전을 확인하고, 나은서가 "저도 쓸 수 있소이다?"라고 끼어들어 검증표를 단톡방 공유 아이디어로 연결되는 씨앗.

- **직전 전환(브릿지):**
  - 유형: 시간 점프(점심→오후).
  - 건너뛴 폭: 점심 후.
  - 도입 좌표: '오후에 한율은 다시 엑셀을 열었다'.
  - 상태 연속성: 씬3의 단톡 온기·아이디어에서 작업 재개. 온도차: 단톡 따뜻함→집중·반전 발견.
- **등장:** 한율(주·작업), 윤솔(잽·씨앗).
- **장면 목표:** 검증표 완성 + 반전 — 검증표는 만들었는데 이걸 채연주가 소장에게 어떻게 제시하는가, 그리고 채연주 단지 소장이 어떤 사람인지 모른다는 현실 문제 발견. 25화 브릿지.
- **장애물/어긋남:** 검증표 완성 후 '이것을 소장에게 제시하는 방식'이 문제 — 채연주 단지 소장이 숫자를 이해하는 사람인지 모른다. 한율이 행운아파트에서 배운 '맞는 답 vs 먹히는 답'의 문제가 여기서도 적용됨.
- **관계 압박/정서적 긴장:** 윤솔이 지나가다 "박 경리, 오늘 또 뭔가 만들고 있어요?" 하고 물음 — 한율이 "검증표요"라고 짧게 답. 윤솔 "어디 거요?" → 한율 "…취업규칙 확인용이요." 윤솔이 잠깐 멈추다 "아, 결재 올릴 거예요?" → 한율 "아직이요" → 윤솔 "그럼 먼저 소장님한테 보여드려야 하는 거 알죠" → 한율 '그게 문제다'.
- **핵심 행동:** 검증표 완성(능동) → 윤솔 한마디에 '소장 제시 방법' 문제 포착 → 반전 자각.
- **감정 비트 흐름:** 검증표 완성(만족) → 윤솔 한마디(전환) → '맞는 답·먹히는 답' 문제 재인식(반전) → 절단.
- **씨앗/회수:** [윤솔 "소장님한테 먼저"] 윤솔이 결재 구조를 알려주는 우군 역할 씨앗. [맞는 답·먹히는 답] 23화 상경 무장해제 비기의 반복 학습 — 한율이 이 화에서 '채연주가 소장을 어떻게 설득하는가'를 고민하게 되는 것.
- **웃음 비트:** 한율이 완성된 검증표를 뿌듯하게 보다가 윤솔 한마디에 뒤통수 맞는 낙차. 한율 속말: *맞는 자료를 만들었다. 그런데 그걸 어떻게 먹히게 만드는가가 남았다. 또.*
- **장면 종료 이미지·반전 절단:**

```
검증표는 완성됐다.
부과 마감 자동화 수식. 야근 단축 가능 시간 역산.
숫자로는 완벽했다.

문제는, 이 숫자를 채연주씨가 소장에게 들이밀어야 한다는 것이었다.
그리고 한율은 그 소장이 어떤 사람인지 몰랐다.

맞는 답을 만들었다.
먹히는 답은 따로 있었다.
```

## 4. 정서·재미 장치

- **회계 능력 = 사람을 구하는 두 가지 결:** (1) 돈을 돌려주는 것 + (2) 일하는 방식을 바꿔주는 것 — 이 화에서 두 번째 결이 처음 전면에 나옴.
- **이현우 잽:** 군기 잔재 + 인강 말투가 짧고 가볍게 코미디 완충.
- **나은서 끼어듦→단톡 공유:** 나은서의 '저도요' 반응이 검증표를 단톡방 공유로 확장하는 자연스러운 씨앗.
- **맞는 답·먹히는 답 반복:** 23화 상경 비기의 반복 학습이 이번 화에서 '채연주 소장 문제'로 연결되며 한율 성장 곡선.
- **RG-2 변주:** "그냥 엑셀이에요" — 베테랑의 겸손처럼 들리지만 실제로 회계법인급 수식임의 낙차.
