## 1. 회차 목적

- **독자에게 줄 것:** 22화 사이다 뒤의 **숨 고르기와 웃음** — 행운아파트 일상 소동 에피소드로 단지 식구들의 캐릭터 애착을 적립. '이 사무소 사람들 재밌다'를 다시 각인.
- **기능(3막 5화차 = 일상 비트·연대 정서 받침):**
  1. **B형 일상 소동:** 행운아파트 입주민 민원 하나를 한율이 현장식으로 처리하는 코미디 — 규정 대응이 아니라 이봉식·박만수의 사람 결로 해결되는 것을 한율이 배움.
  2. **고만옥 온기 비트:** 평상 어르신이 한율에게 무조건적 온기를 주는 짧은 비트. 연대 정서의 배경음.
  3. **채연주 단톡 경과 보고:** 취업규칙 개정 절차가 진행 중이라는 단톡방 짧은 업데이트(가볍게). 완전 해결은 아직이지만 '진행 중'의 온기.
  4. **RG-10 작황 브리핑 + RG-11 무장해제 비기:** 박만수 코미디 라인 활성화. 단지의 러닝 개그가 살아있음을 확인.

## 2. 장면 목록

### 〔씬 1〕 사무소 아침 — 오늘의 현장 소동

- **위치/공간:** 사무소 아침. 봄 늦봄. 입주민 민원인 등장.
- **직전 전환(브릿지·직전 회차에서의 전환):**
  - 유형: 시간 점프(22화 오후→23화 며칠 뒤 아침).
  - 건너뛴 폭: 며칠.
  - 이동 동기: 22화 사이다 뒤 일상으로 복귀. 채연주 단지 취업규칙 개정 절차가 진행 중인 사이 행운아파트 일상.
  - 도입 좌표: 어디(사무소 아침)·언제(봄 후반)·누구(한율·상경)·왜(오늘의 현장 소동 — 입주민 민원).
  - 상태 연속성: 22화 사이다 온기 뒤. 온도차: 사이다 여운→일상 사무소 소동(B형 전환).
- **등장:** 한율(주), 상경(민원 응대), 오늘의 입주민(B형 소동 트리거), 고만옥(배경·평상).
- **장면 목표:** B형 일상 소동 — 한율이 규정 대응으로 접근했다가 상경이 '사람의 결'로 먼저 무마하는 것을 보는 한 칸 배움.
- **장애물/어긋남(§1-C §2 한율 오판):** 입주민 민원(예: 단지 내 주차 구역 이슈·짧게)에 한율이 관리규약 조항으로 대응하려다 — 상경이 "어머~ 선생님 예전에 저기 주차하셨죠? 그때 차 색이 바뀌셨어요?" 하고 전혀 다른 방향(기억·친밀감)으로 민원인을 무장해제하는 것. 한율이 규약을 꺼내들었는데 상경이 먼저 문제를 닫아버리는 낙차.
- **관계 압박/정서적 긴장:** 한율의 '맞는 답 vs 먹히는 답' 반복 학습 비트. 이번엔 억울함보다 가벼운 자기 인식("또 그랬네")으로 처리.
- **핵심 행동:** 민원 등장 → 한율 규약 꺼내듦 → 상경이 기억+친밀감으로 먼저 해결 → 한율 뒤늦게 규약 접음.
- **감정 비트 흐름:** 민원 등장(긴장 짧게) → 한율 규약 반사(직업병) → 상경 무장해제(웃음·통쾌) → 민원인 돌아감 → 한율 속말("또 그랬네").
- **씨앗/회수:** [상경 무장해제 비기] RG-11 변주. [한율 "또 그랬네"] 자기 인식 성장 비트(백영자 4막에서 더 깊어지는 학습의 전단계).
- **웃음 비트(핵):** 상경이 "어머~ 선생님 그때 빨간 차 아니셨어요?" 하는 순간 민원인이 "어떻게 아셨어요?" 하며 표정이 풀리는 것. 한율이 규약 조항을 꺼낸 채 멍하니 서 있는 낙차. 상경: "우리 한율씨는 규약을 너무 믿어~" (한율 속말: *그게 맞는데.*) ★가볍고 따뜻하게.
- **장면 종료 이미지:** 민원인이 웃으며 나가고, 한율이 규약을 서랍에 넣는다.

### 〔씬 2〕 단지 공용공간 — 고만옥의 무조건적 온기

- **위치/공간:** 단지 평상 앞. 봄 낮. 고만옥 어르신이 있는 자리.
- **직전 전환(브릿지):**
  - 유형: 장소 이동(사무소→단지 공용공간) + 시간 점프(아침→낮).
  - 건너뛴 폭: 오전 중.
  - 이동 동기: 한율이 점심 전 잠깐 단지를 돌다가 고만옥과 마주침.
  - 도입 좌표: '평상 앞에 고만옥이 있었다'.
  - 상태 연속성: 씬1의 가벼운 자기 인식 뒤 단지 산책으로 전환. 온도차: 사무소 코미디→평상 온기.
- **등장:** 고만옥(온기 제공), 한율(받는 쪽).
- **장면 목표:** 고만옥이 한율에게 무조건적 온기(옥수수 또는 믹스커피)를 주는 비트 — '아무것도 안 묻고 밥부터 챙기는' 환대가 연대 정서의 배경음으로 깔림.
- **장애물/어긋남:** 한율이 "아 괜찮습니다"라고 반사 거절 → 고만옥이 "손이 닳아서 만든 건데 안 받으면 어떡해요, 우리 아가씨" 하며 무조건 쥐여줌. 한율이 '받아도 되는가'를 또 계산하다가 그냥 받는 것.
- **관계 압박/정서적 긴장:** 고만옥의 오지랖이 한율에게 '결혼은 했냐'로 넘어가려는 찰나, 이봉식이 지나가다가 "어르신, 저기 저 분이 찾으시는 것 같던데요"라고 무심한 타이밍에 끼어들어 결혼 오지랖을 차단 — 이봉식의 단지 정보망이 결혼 오지랖 방어막으로 기능하는 코미디.
- **핵심 행동:** 고만옥 온기 수용(믹스커피/옥수수 받음) → 결혼 오지랖 시작 → 이봉식 개입·차단 → 한율 안도.
- **감정 비트 흐름:** 고만옥 무조건 온기(따뜻) → 결혼 오지랖 시동(긴장·코미디) → 이봉식 차단(웃음) → 한율 안도(웃음).
- **씨앗/회수:** [고만옥 "우리 아가씨"] 한율에 대한 무조건적 환대 — 후반 Q1(정체 알고도 그대로 대해주는) 씨앗. [이봉식 결혼 오지랖 방어막] 이봉식 케미 한 컷.
- **웃음 비트(핵):** 이봉식이 "어르신, 저기 저 분이 찾으시는 것 같던데요"라고 하는데, 고만옥이 "어디요?" 하고 두리번거리는 사이 이봉식이 한율에게 눈짓. 한율 속말: *아무도 찾는 사람 없었다. 그런데 이봉식이 왜 그 말을 했는지는 알았다.* ★가볍게·따뜻하게.
- **장면 종료 이미지:** 한율이 식은 믹스커피를 들고 사무소로 돌아간다. 아직 따뜻하다.

### 〔씬 3〕 사무소 오후 — 박만수의 작황 브리핑 + RG-10

- **위치/공간:** 사무소 오후. 박만수가 사무소에 들어옴.
- **직전 전환(브릿지):**
  - 유형: 시간 점프(낮→오후) + 장소 이동(공용공간→사무소).
  - 건너뛴 폭: 점심 후.
  - 도입 좌표: '오후에 박만수 소장이 들어왔다. 표정이 심각했다'.
  - 상태 연속성: 씬2의 온기 뒤. 온도차: 평상 따뜻함→박만수 심각한 표정(웃음 예열).
- **등장:** 박만수(주·코미디), 한율(반응), 상경(반응), 마초(배경·잽).
- **장면 목표:** RG-10 작황 브리핑 — 박만수가 심각한 표정으로 들어와 "상추가 아직도 영 시원찮아유"라고 하는 것이 전부인 코미디. 진지한 회의 분위기를 작황으로 깨는 패턴.
- **장애물/어긋남:** 박만수가 심각한 표정으로 들어오자 한율이 '이번엔 진짜 큰 민원인가'라고 순간 긴장 — "소장님, 무슨 일이세요?" → "상추가 영 시원찮아서유." 한율의 긴장이 허무하게 풀리는 낙차.
- **관계 압박/정서적 긴장:** 마초가 "소장님, 상추가 왜 안 크는지 제가 봤더니 토양 산도 문제 같아서요~" 하며 진지하게 상추 토론에 합류. 상경 "어머 두 분 또 시작이에요"(RG-10 패턴 인식). 한율이 속말 *이 사람들은 왜 이러는가*에서 *이 사람들이 왜 이러는지 이제는 알겠다*로 한 칸 이동.
- **핵심 행동:** 박만수 작황 브리핑(코미디) → 마초 합류(확산) → 상경 패턴 인식 → 한율 '이제는 알겠다' 한 칸.
- **감정 비트 흐름:** 박만수 심각한 표정(긴장) → 상추(허무 낙차·폭소) → 마초 합류(확산) → 상경·한율 반응(코미디 정점) → 한율 한 칸 이동.
- **씨앗/회수:** [RG-10 작황 브리핑] 박만수 비밀(새벽 화단 물 주기)의 씨앗 — 독자는 이때부터 '저 상추가 왜 저렇게 중요한가'를 어렴풋이. [한율 '이제는 알겠다'] 단지 사람들에 스며드는 편입 곡선 한 칸.
- **웃음 비트(핵):** 박만수 "올해 3동 화단 상추가 작황이 영 시원찮아서유. 이게 비료 문제인지 일조량인지…" (마초: "소장님, 저도 봤는데 뿌리 활착 문제 같았어요~") (상경: "어머 두 분 진짜 농사 지으시는 거예요?") (한율 속말: *이 분들은 관리사무소 직원들이다. 상추 얘기가 왜 이렇게 심각한가.*) → 정적. 박만수: "그나저나 한율씨, 이번 달 부과 잘 됐어요? 허허." 완전한 전환.
- **장면 종료 이미지:** 박만수가 나가고 사무소가 다시 조용해진다. 한율이 창밖 화단 쪽을 잠깐 본다.

### 〔씬 4〕 저녁 — 단톡방 경과 + 코미디 절단

- **위치/공간:** 사무소 저녁. 한율 자리·폰. 단톡방.
- **직전 전환(브릿지):**
  - 유형: 시간 점프(오후→저녁).
  - 건너뛴 폭: 오후~저녁.
  - 도입 좌표: '저녁이 됐을 때 단톡방에 채연주 메시지가 들어왔다'.
  - 상태 연속성: 씬3의 코미디 온기에서 단톡방으로. 온도차: 사무소 코미디→단톡방 채연주 경과.
- **등장:** 한율(주), 채연주(단톡·경과 보고), 나은서(단톡·분위기).
- **장면 목표:** 채연주 취업규칙 개정 절차 진행 중이라는 경과 보고(가볍게) + 단톡방 코미디로 코미디 엔딩 완성.
- **장애물/어긋남:** 채연주가 "저희 소장님이 그거 뭔지 잘 모르신다고 하셔서여ㅠㅠ 제가 직접 찾아가서 설명해야 할 것 같아여" — 예상보다 절차가 더디다는 것. 한율이 '예상한 장애물이다'는 반응(과잉 걱정 0·차분하게).
- **관계 압박/정서적 긴장:** 채연주가 "제가 소장님한테 이런 걸 요구해도 되는 건지 모르겠어여ㅠㅠ" — 자책형 패턴 재등장. 한율이 "요구가 아니에요. 절차예요"라고 짧게 답하는 것.
- **핵심 행동:** 채연주 경과 보고 → 한율 "절차예요" 답장 → 나은서 드립으로 마무리.
- **감정 비트 흐름:** 채연주 경과(짠함·아직 현재진행) → 한율 "절차예요"(안심) → 나은서 드립(웃음) → 채연주 이모티콘(온기) → 코미디 절단.
- **씨앗/회수:** [채연주 소장 장애물] 26화 합법 처리 복선. [한율 "요구가 아니에요. 절차예요"] 채연주 자책에 대한 반복 대응 → 나중에 채연주가 이 말을 자신에게 쓰는 것으로 회수 가능.
- **웃음 비트(코미디 엔딩 핵):** 나은서가 "슨배림 오늘 단지에선 상추 얘기도 하셨소이다?" 하고 뜬금없이 (한율이 씬3 상추 얘기를 한 마디 흘렸거나, 나은서가 맥락 없이 던지거나). 한율 정확체 "…어떻게 알아요?" 나은서 "그냥 슨배림 단지에서 그런 일이 있을 것 같아서요." 한율: "…" 상경이 들어오며 "어머 뭐예요 왜 조용해요?" 하는 것. ★코미디 엔딩 — 가볍고 따뜻하게 닫음.
- **장면 종료 이미지·코미디 절단:**

```
한율이 폰을 내려놨다.
오늘 단지에선, 상추가 걱정이었다.
사무소에선, 결혼이 걱정이었다.
단톡방에선, 절차가 걱정이었다.

한율의 걱정은 세 곳에 나뉘어 있었는데,
그게 이상하게 나쁘지 않았다.
```

## 3. 사건 동선

- **물리 동선:** 사무소 아침(씬1) → 단지 공용공간 낮(씬2) → 사무소 오후(씬3) → 사무소 저녁·단톡방(씬4).
- **독자 시선 순서:** ①상경 무장해제 학습(코미디·한율 한 칸) → ②고만옥 온기+이봉식 방어막(웃음·따뜻) → ③박만수 작황 브리핑(코미디 핵) → ④채연주 경과+코미디 절단(연대 정서 완성).

## 4. 정서·재미 장치

- **B형 핵심 코미디 3종 세트:** 상경 무장해제 비기(씬1) + 고만옥+이봉식 콤보(씬2) + 박만수 작황 브리핑(씬3).
- **편입 곡선 한 칸:** 한율이 '이 사람들이 왜 이러는가'에서 '이제는 알겠다'로 이동 — 말로 설명하지 않고 속말로 짧게.
- **연대 정서 배경음:** 고만옥 온기·채연주 경과가 단지 안팎의 연결을 조용히 받침.
- **RG-10 활성화:** 박만수 상추 타령은 독자가 이미 알고 있는 러닝 개그가 이번 화에서 한 번 더 발화 — '또 나왔다'는 반가움.
- **코미디 엔딩 설계:** 나은서의 '그냥 그럴 것 같아서요' 드립이 논리가 없지만 맞아 떨어지는 황당함. 한율의 정지가 펀치라인.

## 6. prose-writer 인계 메모

- **제목:** 「봄 사무소 — 이 단지엔 뭔가 있다」(3막 5화차 — '뭔가 있다'는 미스터리가 아니라 '이상한 정이 있다'는 결).
- **★B형 설계:** 규정 대응이 아닌 '사람의 결'로 문제가 풀리는 것을 한율이 또 배우는 회차. 단 22화 사이다 뒤라서 한율이 크게 억울해하지 않고 "또 그랬네" 가볍게.
- **★RG-10 박만수 작황 브리핑:** "상추가 영 시원찮아유" 한 줄 + 마초 진지하게 합류 + 한율 속말. 너무 길게 쓰지 않기(6~10줄이면 충분, 리듬이 핵심).
- **★고만옥 씬:** 짧고 따뜻하게. 결혼 오지랖 시작 → 이봉식 차단 → 웃음. 한율의 '받아도 되는가' 계산 → 그냥 받음의 작은 편입 비트.
- **★채연주 경과:** 가볍게 처리. "소장님이 잘 모르신다"는 장애물만 언급, 긴 설명 0.
- **분량 배분(목표 5,000~5,500자):** 씬1 ≈ 1,200 / 씬2 ≈ 1,100 / 씬3 ≈ 1,400(코미디 핵) / 씬4 ≈ 1,000.
- **계절 인장:** 봄 후반. 평상·화단·봄 저녁.
- **호칭/본명 가드:** 위장명 '한율'. 채연주 대면 0.
- **★24화 인계 훅:** 채연주 소장 장애물 → 24화에서 한율이 엑셀 검증표·야근 단축 방안을 설계해 채연주가 소장에게 직접 제시할 수 있도록 돕는 회차.
