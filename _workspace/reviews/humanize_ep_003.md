## 적발한 AI 티 & 처치

### 1. 회계-비유 클러스터 과밀 (최대 AI 티)
초고는 한율 내면을 "차변/대변/분개/전표/환율/줄을 맞추다"로 약 10회 닫음 — 같은 개념적 농담의 반복. 1·2화는 화당 1~2회로 절제.
- 환율 패스: "표현과 의미가 정반대로 매겨지는 회계라니" (비유 던지고 곧바로 설명 = 설명충) 삭제, "차변과 대변이 뒤집힌 전표 같았다" 한 줄만 남김.
- 엔딩: "차변과 대변처럼 마주 섰는데, 합계가 맞지 않았다" + "차대가 안 맞는 전표는, 어딘가 분개가 틀린 것이다" — **같은 뜻 비유 2연발(재진술)**. 뒤 문장 삭제, "아무리 더해도 합계가 맞지 않았다"로 압축.
- 결과: 차변1·대변1·분개1·전표2 = 총 5회. 각 1회씩 다른 기능(통역 낙차 / 합계 불일치 / 분개되지 못함).

### 2. 기계적 삼·사항 병렬 나열
- "환급도, 충당금도, 잡수입도 —" → 삭제(앞 세 줄 메모와 중복).
- "견적서도, 봉투도, 환급 보류도, 충당금 업체 선정도." → "또 회장이었다."로 압축(직전 3줄 리스트와 중복 재진술).
- "직원들이 굽힌 등도, 상경의 멈춘 손도, 다 같은 방향을" → 한 호흡으로 풀어 병렬감 완화.

### 3. 메타 표현(서사 밖 화수 의식)
- "1화부터 단지 곳곳에 손이…" → "첫날부터…"
- "1화부터 이름만 떠다니던 사람" → "그동안 서류 위에서 이름으로만 굴러다니던 사람"
- 소설 본문이 자기 회차 번호를 의식하는 건 전형적 AI 티 → 서사 내부 시간 표현으로.

### 4. 긴장 신체화·손 멈춤 반복
- 식은땀 2회 중 2번째("식은땀이 또 한 줄. ...가까워서, ...가까워서") — 병렬 반복 + 직접 진술 → "등이 또 서늘해졌다. ...손까지 자꾸 앞서 나갔다. 여기서는 잘하는 게 표가 났다."로 변주(직접 진술 '위험이었다'를 보여주기로).
- 본명 엉킴 묘사 "두 글자가 자리를 바꾸려다 제자리로" (기교적) → "혀끝에서 결과 율이 잠깐 엉켰다"(입말·감각).
- 박만수 "허리를 굽혔다" 2회 동일 → 2번째 "고개를 조아렸다"로.
- 상경 손 멈춤 "정전기 같은"(2화 직유 복붙) → "정전기가 한 번 튄 것처럼"(콜백은 유지, 복붙감 제거).

### 5. 감정 직접 진술 / 너무 깔끔한 수습
- "저 사람도, 한때는 나 같았겠구나"(공감 정리) → "다 청구해야져, 하던 그 단정한 목소리가 어디까지 가봤다가 돌아온 건지 가늠이 안 됐다"(정리 대신 미해결 여운, 윤솔 시그니처 라인 콜백).
- "체념과, 체념으로 다 못 덮은 무언가" (doubling + ' 무언가' placeholder) → "체념이 끝까지 덮어주지 못한 자리가 한 군데"(구체화).

### 6. 엔딩 1화 자기복제 완화
초고 엔딩이 1화 엔딩(서랍/식은 커피/사물 나열/"이상하게 차마 버려지지 않았다")을 거의 복붙. 모티프 에코는 **유지하되**:
- "셋째 날 동안 모인 작은 것들이 함께 있었다" + 3항 나열 → "셋째 날이 흘리고 간 것들이 굴러 있었다" + 2항(슨배림 '목소리'는 무형이라 물리적 서랍 리스트에서 빠짐 — 온기는 직후 나은서 대사에 이미 존재).
- "이상하게 차마 버려지지 않았다" → "첫날 것처럼 차마 버려지지 않았다"(에코를 **명시적 콜백**으로 전환 — 복제가 아니라 의도된 반복임을 드러냄).
- "끝내 줄을 맞추지 못한 것들"('줄 맞추다' 4회째) → "끝내 분개되지 못한 채 섞여 있었다".

## 보존(의도적으로 안 건드림)
- 상추 작황 코미디 비트(박만수×나은서 응애 티키타카) — 타이밍·웃음 그대로.
- "정적." / "엉성한데, 이상하게 따뜻했다"(1화 에코 시그니처).
- 회장 "그것밖에 못 했냐"=칭찬 통역 / 본명 러닝개그 / 손난로 반전 / 오독(Q2) 전부 의미 불변.
- 미세 위화감 단락(빼돌리는 사람이 왜 드러내놓고?) — 캐논 보존 핵심, 의미 불변·표현만 다듬음("너무 드러나 있었다"→"너무 환했다").
