## ★ continuity 검수 권고 반영 (5개 항목 전부 처리)

### [중대] 21화 — 정체 환기 비트 위치 이동

- 권고: 채연주 "안 사라지게여"+피식 이후, ◇◇◇ 직전으로 이동
- 처리: 기존 위치(채연주 단톡방 감사 메시지 앞)에서 → 채연주 "안 사라지게여" 발화·한율 피식 직후·◇◇◇ 직전으로 재배치 완료
- 비트 내용: "책으로 배운 게 아니라는 건…그래도 오늘은 그게 다행이었다." (2줄 → 1줄 압축 병행)
- 근거: 정체 자각 비트가 감사 단톡방 앞에 있으면 흐름이 역전됨. 단톡방 온기 씬 이후 여운으로 배치해야 서사 호흡 맞음.

### [경미] 20화 — 정봉구 직책 표현 수정

- 권고: "소장 해먹는 거 아녀" → 직책 맞는 표현
- 처리: "나도 괜히 시설 자리에 있는 게 아녀."로 수정
- 근거: 정봉구는 시설담당이지 소장이 아님. 해유체 억양 보존.

### [경미] 21화 — 박만수 결근 연락 경로 수정

- 권고: "경비실 전화" → 윤솔 경유
- 처리: "전화 한 통이 와 있었다. 경비실에서였다. 소장님이 오늘 안 나오신다고…" → "윤솔이 짧게 말했다. / '소장님한테 연락 왔어요. 오늘 안 나오신다고.'"로 교체
- 근거: 박만수가 경비실에 연락한다는 설정 없음. 관리사무소 내 일반 연락 경로=윤솔.

### [경미] 주석 엔딩 타입 정정 (16화·17화·18화)

- 16화: 하단 주석 "→17 서스펜스" → "→17 감동·여운"
- 17화: 헤더 "엔딩=서스펜스", 하단 엔딩 타입 줄 전면 재작성 → "엔딩=감동·여운 (벚꽃 아래 존 홍 부탁·C형 군불)"
- 18화: 직전 회차 연결 단락 내 "서스펜스" 언급 포함 4곳 → 전부 "감동·여운"으로 정정
- 근거: beatsheet 확정 기준 16~18화는 감동·여운 타입. 서스펜스는 19화~.

### [경미] 분량 표기 통일

- 16~21화 전 화차 주석 분량 표기를 "5,000~5,500자(공백 포함)"으로 통일
- 기존 혼용: "공백 포함 5,000~5,500자" / "5,600자(공백 제외)" / "약 5,100자(공백 포함 기준)" 등
- 처리: 전 화차 통일 완료

## 휴머나이즈 윤문 — 화차별 처치 내역

### 16화 (ep_016_봄사무소_번호를못알려드립니다)

**적발:** 설명충 재진술 — 규정 운용 방향 요약 정리문
- 위치: "경비원의 사생활도 지키고, 급한 입주민도 연결되고. 같은 규정을 막는 데 쓰면 누군가 다치는데, 돌아가는 데 쓰니 아무도 안 다쳤다."
- 이유: 직전 장면에서 독자가 이미 본 것을 작가가 친절히 요약. 10·12·14화 계열 처치 반복.
- 처리: 전체 삭제 (장면 자체로 충분히 전달됨)

**결과:** 본문 1건 삭제. 주석 2건 수정.

### 17화 (ep_017_봄사무소_벚꽃명당의손님)

**적발:** 교훈 아포리즘 직진술
- 위치: "진짜로 편한 사람은, 거짓말할 게 없는 사람이다."
- 이유: 감정 라벨링 + 교훈조 마무리의 전형. 존 홍과의 장면에서 감도가 정점에 달한 직후 작가가 나서서 의미를 정리해버림. 힐링 장르 최대 함정.
- 처리: → "그러니까 이건 편한 게 아니었다." (한율의 자유간접화법으로 전환, 아포리즘 0)

**결과:** 본문 1건 수정. 주석 3건 수정.

### 19화 (ep_019_봄사무소_막내가보낸메시지)

**적발 4건:**

1. **감정 라벨링 + 동어반복** (147행)
   - "한율은 보온병을 들어봤다. 따뜻했다. 아직 온기가 남아 있었다."
   - 이유: "따뜻했다"(과용어) + "온기가 남아 있었다" 동어 재진술 2연. 워치리스트 항목 직격.
   - 처리: → "한율은 보온병을 들어봤다. 손바닥이 데워졌다." (동작형 단문)

2. **"손이 멈췄다" 화내 4회 과밀** (74·125·261·330행)
   - 이유: 74행(도/돈 얘기만 하는 애)·125행(혼자예요)·261행(맞는 말이었다 앞)·330행(0원 확인) 4회. 화당 2회 이내+정점 1회 보호 원칙 위반.
   - 처리: 74행(정점 보존)·330행(엔딩 전 정점 보존). 125행 → "그 한 줄을 다시 읽었다". 261행 → "잠깐 폰을 내려다봤다".

3. **3연 관찰 + 명제 요약 정리문** (111~115행)
   - "관리사무소 일은 이상했다. …그 말은 결국 이런 뜻이었다. / 남아서 하되, 남은 흔적은 남기지 말 것."
   - 이유: 3연 병렬 관찰 후 "그 말은 결국 이런 뜻이었다"로 작가가 직접 요약. 12·14·16·17화 계열 처치 반복.
   - 처리: "그 말은 결국 이런 뜻이었다." 1줄 삭제. "남아서 하되…" 직결.

4. **동어 재진술 2연** (242행)
   - "채연주에게 필요한 건 위로가 아니었다. 지금 당장 마음이 놓이는 문장이 아니었다."
   - 이유: 두 문장이 같은 뜻. 두 번째가 조금 더 구체적이므로 첫 문장 삭제.
   - 처리: → "지금 당장 마음이 놓이는 문장은 도움이 안 됐다."

**결과:** 본문 4건 수정. 주석 기수정(이전 패스 완료).

### 20화 (ep_020_봄사무소_맞는답과먹히는답)

**적발 1건 (continuity 권고 포함 처리):**

1. **엔딩 교훈조 4연 마무리**
   - "받아내는 게 아니었다. / 앞을 막는 거였다. / 그게 오늘의 답이었다. / 맞는 답과 먹히는 답 사이에서, 겨우 찾아낸 답."
   - 이유: 3·4행이 1·2행의 요약 재진술. "그게 오늘의 답이었다"는 대표적 교훈조 닫기.
   - 처리: 3·4행 삭제 → "받아내는 게 아니었다. / 앞을 막는 거였다." (2연 유지, 타이틀 에코 보존)

**결과:** 본문 1건 삭제 + continuity 직책 수정 1건. 주석 기수정.
