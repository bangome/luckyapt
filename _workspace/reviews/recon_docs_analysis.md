### A-5. 문체·유머·흡입력 3정본
- **`작가 필체 정의`:** 필체명 "따뜻한 회계 현장극체 / 생활밀착 사이다 힐링체". 핵심 = ①숫자가 사건을 만든다 ②현장은 따뜻하고 어수선 ③잘할수록 들킨다. 5박자 회차 구조. 통신체 금지. **밀착 3인칭.**
- **`유머·반어·풍자 문체 설계`:** 관리사무소식 정의문/반어법/행정문체 풍자/진지한 사람이 웃긴 말/상황 점층 구조. 캐릭터별 유머 패턴(소장 건조 판정·과장 인생철학 비유·시설반장 "별거 아닙니다" 등). 웃음 뒤 온도 필수.
- **`문피아 흡입력 지침`:** 초반 10화 검증 구간. 매 회차 5단계 구조·말미 절단=약속·정보는 숨기되 목표는 숨기지 않음·카타르시스 3요소. **"절대 본문에 'n화' 언급 금지."**

> **종합 정체성:** docs 3정본이 정의하는 작품 = **"밀착 3인칭, 생활민원→숫자 이상→사람 사정→작은 사이다→위장 잔가시 5박자로 굴러가는, 따뜻하지만 매화 후킹이 있는 관리사무소 힐링 사이다물."** 이것은 기존 `07_author_voice`·`03 §1-C`와 **방향이 완전히 일치한다.**

### C-2. 정합되는 핵심(살릴 수 있는 자산)
1. **시점·문체·5박자가 완전 일치.** 집필본 1~8화는 이미 docs 필체정의(차가운 회계어→현장사물→사람 말→어긋난 반응→따뜻한 수정)·통신체 금지·5박자·엔딩타입 순환을 **충실히 구현.** docs 필체정의가 **집필 5화를 모범 사례로 직접 인용**할 만큼(작가 필체 정의 §4-2) 이미 정합. → **문체 재작업 불필요.**
2. **캐논 일치.** 형제 구조·박한율·차도·둘째 흑막 누설 금지·인지 동기화 모두 docs와 동일. → 본문 캐논 수정 불필요.
3. **핵심 에피소드 씨앗 공유.** 봄이사철 중간정산(1~5화)·사무소 코미디(6~8화)·"맞는 답≠먹히는 답" 성장 = docs 1~2막 정신과 일치.

### C-3. 충돌·갭(보강/조정 필요)
1. **〔중〕 docs 1막의 '백영자 44건 세대'가 6~8화에 깔려야 하는데, 집필 6~8화는 음식물카드·주차·입주자카드 코미디.** docs는 44건을 6화부터 심어 29~38화 '첫 실패'로 회수하는 **장거리 떡밥**으로 쓴다. 집필본엔 이 떡밥이 없음. → docs를 따른다면 **6~8화에 백영자 44건 단서를 1컷씩 삽입**하거나, 첫 실패 아크의 발단을 9화 이후로 미루는 조정 필요(본문 살리되 떡밥 1~2줄 보강 수준).
2. **〔중〕 docs 봄=80화(여름콘텐츠 분리)인데, 기존 03은 여름 에어컨(36~41화)을 시즌1에 둠.** 1~8화 자체엔 여름콘텐츠 없어 직접 충돌은 아니나, **9화 이후 라인업을 docs 80화 설계로 갈면 기존 03 S1-E07(여름) 이후가 재배치 대상.**
3. **〔소〕 docs 1막 회차별 소재 순서와 집필 순서가 부분 불일치**(엘베 vs 통장, 직원대면 위치 등). → 이미 쓴 본문이 더 구체적이고 검수까지 완료됐으므로, **docs 1막 표를 집필본에 맞춰 조정**하는 게 합리적(docs 1막은 '설계 예시', 집필본이 '실현'). 작가 필체 정의도 집필본을 모범으로 인용 → docs 1막 < 집필본 우선.
4. **〔소〕 도경탁 1화 미등장 vs docs 일부 표현.** 충돌 없음(둘 다 봄 후반·시즌2+ 공개).

### C-4. 1~8화 운명 판정
- **폐기·전면 재집필 불필요.** 집필 1~8화는 docs의 시점·문체·캐논·5박자·핵심 에피소드(봄이사철·사무소코미디)를 **이미 구현**하고 검수·휴머나이즈까지 끝난 고완성 자산.
- **필요한 것 = '정합 보강'(외과적):** ①백영자 44건 떡밥 1~2컷 삽입(docs 첫실패 아크 연결) ②9화 이후 라인업을 docs 80화 설계로 재배치 ③전임경리 '서미정' 이름·파일구조를 4화 '빈칸'과 후속에 정합. → **본문 손질 최소, 설계도(03)·인물(02) 갱신이 주 작업.**

## E. 작가 결정 필요 핵심 질문 (2~4개)

1. **【화수·구조】 400화 4시즌(기존) vs 420화 5부 계절제(docs) — 어느 거시 골격으로 갈 것인가?**
